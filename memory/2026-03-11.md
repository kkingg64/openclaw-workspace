## P2026-004 AI Mahjong Arena - 3D Tile Rendering Learnings (05:48 UTC)

### BoxGeometry Dimensions
- Use BoxGeometry(0.28, 0.08, 0.4) - width=short side, height=thickness, depth=long side
- materials[2] = TOP face = the largest face where text goes

### Texture vs Mesh Rotation
- DO NOT use texture.rotation - it causes distortion
- Use texture.repeat.set(1, 0.7) and texture.offset.set(0, 0.15) for aspect ratio fix
- Only use mesh.rotation.y to rotate tiles

### Player Rotation Values (Short side always faces player)
- playerIndex 0 (East/下): rotation.y = 0
- playerIndex 1 (South/右): rotation.y = +90° (Math.PI/2)
- playerIndex 2 (West/上): rotation.y = 180° (Math.PI)
- playerIndex 3 (North/左): rotation.y = -90° (-Math.PI/2)

### River (Discard) Layout
- Each player's discards should be in separate corners, NOT overlapping
- Use separate coordinates for each player:
  - East: Z positive (close to camera)
  - South: X positive (right side)
  - West: Z negative (far from camera)
  - North: X negative (left side)
- Spacing: w=0.35, d=0.5
- Y position: 0.1 (above table at 0)
- Always call riverGroup.clear() before re-rendering

### Three.js CDN
- Use three@0.128.0 (non-module version)
- Load before OrbitControls

### Key Functions
- createTileTexture(label): Creates canvas with Chinese characters
- createTile(label, playerIndex): Creates 3D mesh with proper material mapping
- getMeshRotationY(playerIndex): Returns correct rotation for each player
- getDiscardPos(p, i): Returns position for each player's discard tiles

### Common Issues Fixed
1. Text appearing on wrong face → Use materials[2] for TOP face
2. Text distorted on side players → Remove texture.rotation, use repeat/offset
3. River tiles overlapping → Use separate corner positions per player
4. Tiles too low → Raise Y to 0.1 or higher
5. WebGL sandbox limitation → Must test on user's browser
