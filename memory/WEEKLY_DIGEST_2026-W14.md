**價值：⭐⭐⭐⭐⭐ | 領域：AI SaaS 變現**

$299/mo係AI Agent SaaS嘅轉化率高峰——心理學稱之為「Anchor Effect」。企業願意付「結果」而不是「功能」；願意付「投資」而不是「工具」。

**核心洞察：**
- $99/mo = 感覺係「貪平」，決策者怕被問責

- $899/mo = 企業級，「Strategy investment」

**行動：** 新AI SaaS产品唔好用成本加成法定價，改用「30% of pain cost」法則——先計算客戶每月因呢個問題損失幾多錢，再乘以30%。

### 10. 💹 AI Agent SaaS定價：Outcome-based係未來，Seat-based係過去
**價值：⭐⭐⭐⭐ | 領域：AI SaaS Revenue Strategy**

**定價模型演進：**
```
2024主流：Seat-based（$20-50/user/month）→ 企業抱怨「付咗錢AI究竟做咗幾多嘢？」
2026主流：Outcome-based / Hybrid ⭐

Best Practice（Hybrid Model）：
┌─────────────────────────────────────┐
│ Base: $500/month（包括1000 tasks） │
│ Overage: $0.50 per task（超額部分） │
└─────────────────────────────────────┘
→ Vendor：有穩定base revenue
→ Customer：有可預測成本，但又有彈性
```

**定價心理學核心：** 企業願意付幾多 = 佢哋節省/賺到幾多。
- 節省人力成本：「AI agent取代2個全職員工」→ $6K-12K/month budget
- 減少錯誤成本：「减少80% data entry errors」→ 每個錯誤$50 × 1000 = $50K節省
- 加快速度：「4小時→10分鐘」→ 每週節省20小時 × $100/hour = $2K/month價值

**行動：** 唔好用成本加成法定價。先計算客戶嘅pain cost，再乘以30-40% = 你嘅合理價格區間。
