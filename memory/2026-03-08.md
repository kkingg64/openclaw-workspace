## 🔧 Technical Learnings

### Docker Compose Issue
- Old docker-compose v1 had issues with container recreation
- Solution: Use `docker compose` (v2) instead of `docker-compose`
- Key command: `docker compose -f docker-compose.yml up -d --build`

### Node Version Issue
- Next.js 16.1.6 requires Node.js 20.9+
- Fixed by using `node:22-alpine` base image
- Note: Node 18 doesn't support Next.js 16
