### 2. 🔥 Claude Code Camp: Agents That Run While You Sleep

**關鍵資訊 (來源: claudecodecamp.com):**
- 呢位工程師用 Claude Code 整左「訓覺時運行既 agents」
- 發現既核心問題：**點樣知道 agents 既輸出係啱既？**
- 用同一個 AI 寫 code + 測試 = 「self-congratulation machine」

**解決方案 - TDD + Acceptance Criteria:**
1. **寫 Spec 先，後寫 Code** - 用 plain English 寫明每個 feature 既 acceptance criteria
2. **獨立驗證** - 用另一個 AI agent 去驗證 output
3. **Playwright Browser Agents** - 每個 AC 用一個独立 agent 去驗證

**實際工具:** `opslane/verify` - Claude Code plugin
- Pre-flight: 檢查 dev server、auth session
- Planner: 分析 spec 同 changed files
- Browser agents: 並行運行每個 acceptance criteria
- Judge: 最後既 verdict

**商業價值:**
- **信任問題**係企業採用 AI Agent 既最大障礙
- **驗證 + 測試**工具會係 2026 年既藍海市場
- 可以開發類似既 SaaS 工具畀企業用

### 3. 🔥 The 8 Levels of Agentic Engineering

**關鍵資訊 (來源: Bassim Eledath):**

呢個 framework 展示 AI Engineering 既成熟度 levels:

| Level | 名稱 | 描述 |
|-------|------|------|
| 1-2 | Tab Complete + Agent IDE | Copilot / Cursor 基礎 |
| 3 | Context Engineering | 優化 prompt context density |
| 4 | Compounding Engineering | 持續改進每個 session 既提示 |
| 5 | Multi-Agent Orchestration | 多個 agents 協作 |
| 6 | Production Runtimes | 生產環境既 agent 部署 |
| 7 | Agentic CI/CD | 自動化測試 + 部署 |
| 8 | Agent Ecosystems | 完整既 agent marketplace |

**關鍵洞察:**
- 大部分團隊仲响 Level 1-3
- Level 4-5 既團隊已經有顯著既 productivity gain
- **Level 6-7** 係企業採用既關卡 — 需要可靠既 testing + verification
- Level 8 既 marketplace 仲未成熟，但係未來方向

**商業機會:**
- **Level 3-4 既工具** — Context engineering, prompt templates
- **Level 6-7 既工具** — Production testing, monitoring, verification
- **培訓 + 咨詢** — 幫企業提升到更高 level
