**核心功能:**

- 🔧 Vendor Agnostic: 支持 OpenAI、Anthropic、Google、Local (Ollama/LM Studio)

- 🌐 Universal: 支持所有主流 programming languages
- 📈 Consistent Quality: 永遠一致，唔會疲勞

**支持平台:**
- ✅ GitHub (PR 自動 review)
- 🧪 GitLab (Beta)
- 🛠️ Bitbucket (Planned)

**Integrations:**
- ✅ Jira
- ✅ Linear
- 📝 Documentation Generation

**點樣運作:**
```yaml
# .github/workflows/gito-code-review.yml
name: "Gito: AI Code Review"
on: pull_request
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - name: Run AI code analysis
        env:
          LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
        run: gito --verbose review
```
