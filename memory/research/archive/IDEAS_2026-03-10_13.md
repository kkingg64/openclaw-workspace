## 📈 市場趨勢分析

### 1. OpenClaw Skills 生態架構

**Skills 加載位置 (Priority Order):**
| Location | Path | Visibility |
|----------|------|------------|
| Workspace Skills | `<workspace>/skills` | 最高 - 單一 agent 專用 |
| Managed Skills | `~/.openclaw/skills` | 中等 - 所有 agents 共享 |
| Bundled Skills | 安裝包內建 | 最低 - 預設 tools |

**Skills 格式要求:**
- `SKILL.md` + YAML frontmatter
- 必須包含: `name`, `description`
- 可選: `homepage`, `user-invocable`, `command-dispatch`

**Gating (負載過濾):**
```yaml
metadata: {"openclaw": {"requires": {"bins": ["uv"], "env": ["API_KEY"], "config": ["browser.enabled"]}}}
```
- 可按 binary、環境變數、config 條件性加載

### 2. ClawHub - OpenClaw 官方 Skills Registry

**功能:**
- Public skills marketplace: https://clawhub.com
- Install: `clawhub install <skill-slug>`
- Update: `clawhub update --all`
- Sync: `clawhub sync --all`

**預設安裝路徑:** `./skills` (workspace root)

**變現機會:**
- Skills 可以收費 (future feature?)
- Featured/ promoted listings
- Enterprise skill packs (客製化)

### 3. Claude Code Plugins 生態

**Claude Code (Anthropic):**
- Terminal-based agentic coding tool
- 理解 codebase、執行 routine tasks、處理 git workflows
- Plugin system: custom commands + agents

**官方 Plugin 安裝:**
- 透過 npm 安裝 (deprecated: `npm install -g @anthropic-ai/claude-code`)
- Recommend: `curl -fsSL https://claude.ai/install.sh | bash`

**Plugin 類型:**
| Type | Description | Examples |
|------|-------------|----------|
| Custom Commands | /slash commands 擴展 | `/bug`, `/test` |
| Agents | 自定義 agent behavior | Code review, security scan |
| Tools | 額外 tool integrations | Database, API, cloud |

2. **Skill Composability** - skills 可以組合，形成複雜 workflows

**定價:**
