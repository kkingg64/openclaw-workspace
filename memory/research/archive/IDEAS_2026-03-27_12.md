### 二、n8n 生態現況分析

#### n8n 係咩？
開源 workflow automation tool，可以連接 400+ apps，用視覺化方式整 automation。

#### 2026 現況
- **估值：** 2025 年達 $1B+ (Unicorn)
- **用戶：** 全球 100,000+ 开发者/企業
- **特點：** Open source + Cloud option, AI-first architecture
- **挑戰：** 仍然需要技術理解，唔係真正「小白友好」

#### n8n 弱點（機會）
| n8n 弱點 | 小白痛點 | 解決方案機會 |
|----------|----------|--------------|
| 需要邏輯設定 | 唔知點串連 steps | AI 幫你串連 |
| Variable mapping 複雜 | 搞唔清楚資料流 | 自然語言描述 → 自動生成 |
| Error handling 困難 | 成日壞但唔知點修 | AI 自動修復 |
| Debug 困難 | 壞咗點都搵唔到問題 | AI 幫你 debug |
| 價錢貴 | Cloud 版貴 | 免費開源 + 托管服務 |

### 四、震撼案例：$7 VPS AI Agent

#### 案例：AI Portfolio Doorman
**創辦人：** George Larson
**成本：** $7/month VPS
**架構：**
```
Visitor → Web Chat → IRC Server → AI Agent (nullclaw)
                                    ↓
                            GitHub Repos (Read-only)
                                    ↓
                            Answer with actual code
```

**關鍵創新：**
1. **IRC 作為 AI Transport** - 30年舊 protocol，但係極度簡單 + 零 vendor lock-in
2. **分层 Model 選擇** - Haiku (快速/便宜) + Sonnet (複雜推理)
3. **$2/day 成本上限** - 公有 AI 界面必須有成本控制
4. **Agent-to-Agent 通信** - Google A2A protocol 跨 Agent 協作

**啟示：**
- AI Agent 部署成本已經跌到「垃圾」級別
- 關鍵唔係技術，而係應用場景
- Agent-to-agent 協作係新興軍備競賽

### 七、Agent-to-Agent 協作：新興風口

#### 點解係下一個浪潮？

從 Hacker News 見到：
1. **Cursor × Claude Code** - Agent teams (主 agent + subagents)
2. **Claude + Codex pair programming** - 兩個 Agent 互相 review
3. **Facebook HyperAgents** - Self-improving agents
4. **Google A2A Protocol** - Agent 之間既通信標準

#### 核心概念
```
傳統：Human → AI Agent (1對1)
新範式：Human → AI Agent → AI Agent (多個 Agent 協作)

例如：
- Main Agent 接收任務
- 拆解成 subtasks
- 分配俾 specialized agents
- 收集結果、整合、匯報
```

#### 商機

| 方向 | 機會 | 切入點 |
|------|------|--------|
| **Multi-Agent Orchestration Tools** | 整工具管理多個 Agent | Dashboard、visual flow |
| **Agent Marketplace** | 買賣 specialized agents | 类似 App Store 但係 Agent |
| **Agent Security** | 認證、監控、安全 | 企業剛性需求 |
| **Agent Communication** | A2A 協議、API 閘道 | 基礎設施 |
