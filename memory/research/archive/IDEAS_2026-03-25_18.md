## 📊 MCP 生態地圖 (2026 Q1)

### 1. 什麼係 MCP？

**Model Context Protocol** 係一個開放標準，令 AI 應用可以連接外部系統：
- 數據源：Google Calendar、Notion、數據庫
- 工具：搜尋引擎、計算機、代碼執行
- 工作流：專業化 Prompt

**比喻：** 就係 AI 既 USB-C —— 統一接口，快速連接

### 2. 支援平台

| 平台 | 支援狀況 |
|------|----------|
| **Claude** | ✅ 官方 Connectors 目錄 |
| **ChatGPT** | ✅ OpenAI MCP 支援 |
| **Cursor** | ✅ 官方 Marketplace + cursor.directory |
| **VS Code** | ✅ MCP Servers |
| **OpenClaw** | ✅ (正在使用緊) |

### 3. 熱門 MCP Servers (按用途分類)

**知識管理類：**
- **Notion MCP Server** (3個版本) - 高人氣，大量使用
- **Memory/Knowledge Graph** - 為 AI Agent 提供持久記憶

**數據/分析類：**
- **DexPaprika** - 加密/DeFi 數據，即時 + 歷史
- **Doc (9000+ libraries)** - 文件查詢，避免 AI 幻覺
- **Database Metadata** - 跨數據庫查詢

**爬蟲/數據獲取類：**

## 💰 Skill-as-Tool 變現機會

### 點解 MCP Servers 係下一個金礦？

**傳統模式：**
- 賣 Prompt → 容易被複製
- 賣課程 → 需要不停更新
- 賣 Template → 門檻低競爭大

**MCP Server 模式：**
- 賣 Tool → 用戶綁定，越用越依賴
- API 調用收費 → 被動收入
- 專業化 Server → 高毛利

### 🔥 可以立即做既 MCP Server 類型

**1. 行業專屬數據 Server**
- 原理：提供某個行業既即時數據 API
- 例子：房地產數據、競品價格監控、招聘數據
- 變現：API 調用量收費

**2. 專業工具 Server**
- 原理：將某個專業軟件變成 AI 可調用既 Tool
- 例子：Figma、Linear、Salesforce MCP Server
- 變現：OAuth 認證 + 企業訂閱

**3. 工作流自動化 Server**
- 原理：封裝複雜工作流為單一 MCP Tool
- 例子：自動發布社交媒體、自動化報告生成
- 變現：每月訂閱

**4. 本地數據 Server**
- 原理：讓 AI 安全訪問本地文件/數據庫
- 例子：PDF 分析、Excel 處理、本地文件搜索
- 變現：一次性付費或訂閱
