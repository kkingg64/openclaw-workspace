### 🔥 YC W26 重要趨勢分析

#### Captain (YC W26) — 自動化 RAG 解決方案

**產品定位:**
- 話係「Accurate knowledge search that scales」
- 全托管 RAG pipeline，唔洗維護

**關鍵數據:**
- **95% 準確率** (vs 傳統 RAG 既 ~78%)
- **幾分鐘部署** (vs 3-6 個月)
- SOC 2 Certified
- 支持 SharePoint, S3, GCS, Azure 整合

**定價模式:**
- Managed Vector Storage (唔洗 external database)
- Role-Based Access Control (企業級安全)
- 可能走 SMB + Enterprise 雙軌

**市場定位:**
- 對手: LangChain (太多選擇)、Enterprise RAG (太貴)
- Captain 填補中間: 中價位、易用、高準確率

---

#### Context Gateway — Agent Context 壓縮

**產品定位:**
- 「壓縮 agent context before it hits the LLM」
- 降低 LLM token 成本

**技術亮點:**
- Context compression before LLM processing
- 呢個方向解決緊 AI Agent 既成本痛點

**商機分析:**
- 所有 AI Agent 都會遇到 context window 限制
- 壓縮技術可以降低成本 30-70%
- 可以独立產品化，亦可以整合到現有 Agent 框架
