## 📈 今日熱點：AI 經濟學大揭秘

### 1. Anthropic Claude Code 成本迷思 (source: Hacker News)

**關鍵發現:**
- Forbes 報導話 Claude Code Max 用戶每月消耗高達 $5,000 API 費用
- **但呢個係零售價，唔係實際成本！**
- OpenRouter 上類似既大型模型收費只係 Anthropic 既 **10%**

**商業啟示:**
- **Inference 成本被嚴重高估** — 呢個 narrative 對 frontier labs 有利
- 如果 Anthropic 對 power user 既真實成本約 $500/month，佢仍然有錢賺
- 平均用戶 $180/month 對比 $18/月實際成本 = **10x 利潤空間**

### 2. Oracle AI 數據中心大危機 (source: CNBC)

**關鍵發現:**
- OpenAI 放棄擴張 Oracle 既 Abilene 數據中心
- 原因：** Nvidia 晶片每年升級一次，太舊既硬件唔想要**
- Oracle 用 $100B debt financing 但硬件過時既風險極高
- Oracle 股價今年跌 23%，較高峰期跌過半

**商業啟示:**
- **數據中心地產呢家嘢有周期風險** — 硬件升級太快
- 有 cash flow 既大公司 (Google, Amazon, Microsoft) 唔怕
- 中小型 AI 基建玩家可能被淘汰
