## 🔍 市場數據

### 1. MCP (Model Context Protocol) 生態爆發

**MCP 係乜？**
- 開放標準 protocol，令 AI 可以連接外部數據源同工具
- 定位係「AI 既 USB-C」- 標準化連接
- 由 Linux Foundation 托管，open source

**支持既客戶端：**
- Claude (Anthropic)
- ChatGPT (OpenAI)
- VS Code
- **Cursor** (重點！)
- MCPJam

**SDK 覆蓋：** TypeScript, Python, Java, Kotlin, C#, Go, PHP, Ruby, Rust, Swift - 幾乎涵蓋曬主流語言

### 2. Cursor - AI Coding Agent 龍頭

**最新發展 (Feb 2026)：**
- **Self-driving codebases** - 部分 multi-agent research harness 已經開放 preview
- **Autonomy slider** - 用戶控制 AI 獨立程度 (Tab → Cmd+K → Full Agent)
- **Enterprise adoption** - **Salesforce 超過 40,000 engineers 採用**，超過 90% developers
- **PR velocity + code quality** 雙位數提升
