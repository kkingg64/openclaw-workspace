## 💰 帶貨文案核心公式

### 高轉化率文案公式

```
【帶貨文案萬能公式】

AIDA 公式:
Attention → Interest → Desire → Action

1. Attention (注意力)
   - 數字: "90%的人都不知道..."
   - 問題: "你是否也在為XXX苦惱？"
   - 驚嘆: "太不可思議了！"
   - 對比: "前後對比太明顯了！"

2. Interest (興趣)
   - 故事: "我曾經也XXX..."
   - 數據: "這個產品在XXX銷量第一"
   - 證書: "獲得XXX認證"
   - 成分: "含有珍貴的XXX成分"

3. Desire (慾望)
   - 場景: "想象一下，當你XXX..."
   - 體驗: "用它感覺肌膚在喝水"
   - 對比: "用之前 vs 用之後"
   - 限量: "限量500份，搶完即止"

4. Action (行動)
   - 指令: "點連結購買"
   - 緊迫: "只剩最後10份"
   - 優惠: "用代碼XXX減20元"
   - 保証: "30天無條件退貨"

【高轉化標題模板】

1. 痛點型:
   "告別XXX，迎接XXX！"
   "XXX問題終於有救了！"
   "XXX人群必備的XXX！"

2. 數字型:
   "3個技巧教你XXX"
   "只要$XX，XXX帶回家！"
   "1000+人都在用的XXX！"

3. 懸念型:
   "這個XXX竟然能XXX！"
   "為什麼XXX都在用這個？"
   "揭秘XXX背後的秘密！"

4. 場景型:
   "旅行/約會/上班必備的XXX"
   "這個XXX改變了我的XXX"
   "在XXX場景下太實用了！"
```

### 避免踩坑的文案禁忌

```
【帶貨文案禁忌】

❌ 過度承諾
- "三天變白" → 可能違反廣告法
- "永久效果" → 無法保証
- "100%有效" → 缺乏可信度

✅ 替代方案:
- "使用28天後明顯改善"
- "配合護理可維持效果"
- "97%用戶反映有改善"

❌ 虛假比較
- "比XXX好10倍" → 缺乏依據
- "工廠直銷便宜50%" → 難以驗証
- "原價999現價99" → 價格欺詐

✅ 替代方案:
- "性價比極高"
```
