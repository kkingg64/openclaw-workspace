## 🎬 Viral Content Format Mechanics

### 1. Transition Format (轉場格式)

**為何有效：**
```
用戶喜歡：瞬間滿足感 (Instant Gratification)
心理機制：看穿套路但仍然期待驚喜
參與度高：用户會研究點做、會挑戰

CBK 應用：
- 出街前 → 成為全場焦點
- 普通妝 → Old Money Aesthetic
- 平價品 → 高級感
```

**CBK Transition Format 公式：**
```
1. 開頭：日常場景（化妝枱、衣櫃）
2. 轉場：電話滑過畫面 / dab動作
3. 結果：Old Money 版本現身
4. 結尾：配上 american wedding 音樂

適用品牌：
- 化妝品（妝前妝後）
- 時裝（平價→高貴）
- 珠寶（簡單→優雅）
- 旅遊（日常→度假模式）
```

## 📈 Instagram Reels Algorithm 2026 Q1

### 演算法 Ranking Signals

```
1. 【Watch Time & Completion Rate】- 最重要
   - 短片越短越好（<60秒最佳）
   - 開頭3秒決定命運
   - 结尾留鈎 (CTA / 期待)

2. 【Engagement Signals】
   - 讚、comment、save、share
   - Save = 最強信號（代表觉得有用）
   - Share = 第二強（主動推薦）

3. 【Rewatch Rate】
   - 多次rewatch = 內容質量高
   - 演算法會推更多流量

4. 【Profile Visits / Follows】
   - 看完片去主頁 = 興趣信號
   - Follow = 長期興趣
```

### Adam Mosseri (Instagram Head) 建議

```
✅ Do：
- No watermarks / logos
- Shorter is better (尽量 <60秒)
- Use trending audio
- Post consistently
- Use trial Reels (先推非follower)

❌ Don't：
- 太多文字 overlay
- Low quality / 暗淡光線
- 抄襲別人内容
- 忽視 CTAs
```
