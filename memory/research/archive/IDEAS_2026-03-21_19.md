
### Skills 變現模式分類

#### 模式 1:一次性付費 Extension/Skill

```
結構:
- 開發者定價 $9-999
- 用戶一次付款，永久使用
- 平台抽成 0-20%

優點:
- 簡單直接
- 用戶無持續付費壓力

缺點:
- 更新維護成本高
- 收入天花板明顯

成功案例:
- VS Code 付費 Extensions: $5-50 的工具類 extension
- 熱門類別: AI code review, Git tools, Database tools
```

#### 模式 2: 訂閱制 Skill-as-a-Service

```
結構:
- 月費 $9-99 或年費 $90-990
- 包含使用量限制
- 超過後按量收費

優點:
- 被動收入
- 可持續迭代
- 客戶價值高

缺點:
- 需要持續提供價值
- 客戶留存壓力

成功案例:
- GitHub Copilot: $10-39/月
- Cursor Pro: $20/月 (包含 AI features)
```

#### 模式 3: 用量計費 (Usage-based)

```
結構:
- 按 API call 收費
- 例如: $0.01 per 1K tokens
- 或按任務收費

優點:
- 收入與價值成正比
- 客戶無前期風險

缺點:
- 收入不穩定
- 需要精確成本計算

成功案例:
- OpenAI API: 按 token 收費
- Anthropic API: 按 token 收費
```

#### 模式 4: Freemium + 增值服務

```
結構:
- 免費版有功能限制
- Pro 版解锁高級功能
- 企業版另收費

優點:
- 低門檻獲客
- 自然升級路徑
- 病毒式傳播

缺點:
- 需要維護兩個版本
- 免費版可能成為純成本

成功案例:
- Cursor: Free + Pro ($20/月)
- Raycast: Free + Pro ($8/月)
```
