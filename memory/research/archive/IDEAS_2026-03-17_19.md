#### 演算法底層邏輯

**TikTok Algorithm 2026:**
- **推薦核心:** Forked-Forest 結構 — 每條片獨立評估，唔似傳統社交平台靠 Followers
- **評分維度:**
  1. **完播率 (70%)** — 前 3 秒決定 80% 命運
  2. **Watch Time (50%)** — 總觀看時長
  3. **Engagement Rate (40%)** — Like/Comment/Share/Save 綜合
  4. **Trend Participation (30%)** — 使用熱門 Sound/Hashtag
  5. **Video Information (20%)** — Description, Tags, Effects

**關鍵洞察:** TikTok 唔 care 你有幾多 followers — 條片本身既 quality 先決

**IG Reels Algorithm 2026:**
- **推薦邏輯:** Hybrid — Feed + Explore 雙軌
- **評分維度:**
  1. **Saves & Shares (最高權重)**
  2. **Comments (特別關鍵)**
  3. **Watch Time (>70% 特別高分)**
  4. **Profile Visits**
  5. **Content Originality (原創內容加权)**
  
**關鍵洞察:** IG 仍然比 TikTok 重視「帳號價值」，Follower 數有影響

**YouTube Shorts Algorithm 2026:**
- **推薦邏輯:** Shorts Feed 獨立於長影片
- **評分維度:**
  1. **Impression-to-Click Rate**
  2. **Audience Retention (獨家)**
  3. **Subscriber conversions (幾多人睇完 Shorts 然後 Subscribe)**
  4. **Trend topics**

## 🎯 病毒式傳播核心密碼

### 1. Hook Formula (前 3 秒定生死)

**黃金結構:**
```
0-1秒: 視覺衝擊 (Visual Hook)
1-2秒: 問題/衝突 (Problem Statement)  
2-3秒: 承諾 (Promise/Value Prop)
```

**成功 Hooks 類型:**

| Hook 類型 | 範例 | 效果 |
|-----------|------|------|
| **問題導向** | 「90% 人都唔知...」 | ⭐⭐⭐⭐⭐ |
| **反傳統** | 「千祈唔好咁樣做...」 | ⭐⭐⭐⭐⭐ |
| **視覺衝擊** | 靚靚 B-roll + Fast Cut | ⭐⭐⭐⭐ |
| **Sound Hook** | 用熱門 Sound 開頭 | ⭐⭐⭐⭐ |
| **數字承諾** | 「3 分鐘教識你...」 | ⭐⭐⭐⭐ |
| **爭議性** | 「我唔同意呢個觀點...」 | ⭐⭐⭐⭐ |

| **Before/After** | 極高 | 全平台 | ⭐⭐⭐⭐⭐ |

### 3. Retention (留人) 技巧

**完播率優化:**

| 技巧 | 例子 | 提升效果 |
|------|------|----------|
| **Fast Pacing** | 每 2-3 秒 cut 一次 | +30% |
| **Looping** | 頭尾連接，無縫 loop | +25% |
| **Information Gap** | 留疑問唔一次過講曬 | +40% |
| **Pattern Interrupts** | 突然轉 tone/畫面 | +35% |
| **End Screen** | 「下一次...」預告 | +20% |

**Watch Time 優化:**
- 將最重要既野放後面 (越後越多人睇)
- 使用「Chapter markers」(YouTube)
- 製造「期待感」

### 4. Engagement 催化劑

**提升互動既技巧:**

| 技巧 | 操作方法 | 預期提升 |
|------|----------|----------|
| **Comment Bait** | 「你認同嗎？話我知」 | +50% comments |
| **Save Trigger** | 「Save 呢條片，等唔好睇漏」 | +30% saves |
| **Share Trigger** | 「分享俾你朋友」 | +20% shares |
| **Question CTA** | 結尾問問題 | +40% comments |
| **Poll/Quiz** | 影片內置投票 | +60% engagement |
