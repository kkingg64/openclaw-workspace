## 🎯 Topic: MCP 生態與 AI Coding Agent 技能市場分析 (2026 Q1)

### 📈 市場觀察

#### 1. Model Context Protocol (MCP) 生態爆發

**MCP 係乜？**
- 開放標準 protocol，用黎連接 AI 應用同外部系統
- 定位係「AI 界既 USB-C」— 標準化連接
- 支持既客戶端：Claude, ChatGPT, VS Code, Cursor, 等等

**關鍵數據:**
| 指標 | 數據 |
|------|------|
| MCP 官方 Server 數量 | 100+ |
| 支持既 AI Clients | Claude, ChatGPT, VS Code, Cursor |
| 主要應用場景 | 數據庫、文件系统、API、第三方工具 |

**商業機會:**
1. **MCP Server 開發服務** — 幫企業整 MCP 連接器
2. **MCP Marketplace** — 預建既 MCP server 交易平台
3. **MCP 培訓** — 企業採用既教育服務

#### 2. AI Coding Agent 工具競爭態勢 (2026 Q1)

**主要玩家:**

| 工具 | 定位 | 價格 | 企業採用 |
|------|------|------|----------|
| **Cursor** | AI-first IDE | $20-40/mo | 50% Fortune 500 |
| **GitHub Copilot** | IDE 助手 | $10-39/mo | Millions |
| **Claude Code** | CLI AI 開發 | 免費/付費 | 開發者 |
| **OpenAI Codex** | Agent 編碼 | API 定價 | 企業 |

**Cursor 亮點 (2026):**
- 支援多 model：OpenAI, Anthropic, Gemini, xAI
- **Agent Mode**：可以 autonomous 開發、測試、demo
- **Salesforce 案例**：40,000 工程師使用，生產力大幅提升
- NVIDIA CEO Jensen Huang 公開讚賞

**趨勢信號:**
- AI Agent 正在由「輔助」走向「自主開發」
- Enterprise 市場爆發 (Salesforce, NVIDIA 等大企業)
- 多 model 選擇成為標準

### 💡 商業洞察

**點解呢個領域有錢賺？**

1. **Enterprise AI 採用加速** — 2026 年企業開始大規模落地
2. **MCP 標準化** — 降低集成成本，創造生態系統
3. **Developer 生產力** — 企業願意為效率提升付費
4. **技能缺口** — 好多人唔識用呢啲工具

**風險因素:**
- 大廠 (Microsoft, Google, Anthropic) 紧係度做類似野
- 技術變化快，技能容易過時
- 企業採用週期長
