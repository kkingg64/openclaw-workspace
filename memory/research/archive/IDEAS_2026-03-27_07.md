## 🔬 AI SaaS 定價現況分析 (2026 Q1)

### 一、AI SaaS  vs 傳統 SaaS 的關鍵差異

**傳統 SaaS 單位經濟學：**
```
毛利 = 70-80%
主要成本 = 伺服器 + 工程師
定價邏輯 = 每用戶/月 (Seat-based)
收入可預測性：高
```

**AI SaaS 單位經濟學：**
```
毛利 = 30-60% (點解低？)
主要成本 = GPU/AI 運算 + 工程師
定價邏輯 = Token 用量 / 任務複雜度 / 結果價值
收入可預測性：低（用量波動大）
```

**核心問題：AI 成本係「變動成本」而唔係「固定成本」**
- 傳統 SaaS：你多用一個功能，server cost 增少少
- AI SaaS：你叫 GPT-4o 做野，每個 request 都係錢
- 結果：收入增長時，利潤率可能下跌

---

### 二、2026 年主流 AI 定價模型

#### 模型 1：Token-based / Usage-based（最常見）

**原理：** 按照 AI 消耗量收費

**例子：**
- OpenAI: $0.01-0.10/1K tokens
- Anthropic: $0.01-0.15/1K tokens
- Midjourney: $10-30/月（fixed tiers + 超過用完）

**優點：**
- 客戶覺得「用幾多俾幾多」公平
- 收入同成本直接掛鉤

**缺點：**
- 收入預測困難
- 客戶可能因為 cost 控制而少用
- 毛利率不穩定

**適合場景：** API 產品、開發者工具

---

#### 模型 2：Outcome-based / Value-based（利潤率最高）

**原理：** 按照 AI 幫客戶賺幾多錢 / 省幾多錢收費

**例子：**
- Harvey AI（法律）：「律所增收部分」收費
- Glean（企業搜索）：按照企業規模收費
- Writer（寫作）：按照「品牌一致性」價值收費

**計算方式：**
```
收費 = 客戶業務價值 × 百分比
例如：幫客戶增加 $100 萬收入，收 10% = $10 萬/年
```

**優點：**
- 可以收得好貴
- 客戶成功同收入綁定

**缺點：**
- 需要證明 ROI
- 銷售周期長
- 談判複雜

**適合場景：** Enterprise AI、High-stakes decision tools

---

#### 模型 3：Hybrid（最流行於 2026）

**原理：** 固定訂閱 + Usage 超額收費

**例子：**
- Jasper: $49-500/月（按功能分級）+ 超過limit加錢
- Copy.ai: $36/月起 + 超過credits收費
- Most AI SaaS: 「Base fee + AI credits」

**為咩最流行？**
```
固定部分 → 收入可預測（對公司）
用量部分 → 成本覆蓋（對供應商）
分級制 → 客戶篩選（對both）
```

**實際例子：**
```
Starter: $29/月
- 1,000 AI credits
- 超出 $0.01/credit

Pro: $99/月
- 10,000 AI credits
- 超出 $0.008/credit

Team: $299/月
- 50,000 AI credits
- 超出 $0.006/credit
```

---

#### 模型 4：Agent-based Pricing（最新興）

**原理：** 按照「AI Agent 完成既任務數」收費

**適合場景：** 流程自動化、RPA 替代

**例子：**
```
Taskbot: $0.50-2.00/任務完成
- 數據輸入：$0.50/筆
- 報告生成：$2.00/份
- 客戶回覆：$1.00/封
```

**優點：**
- 客戶只需要為結果付費
- 容易計算 ROI

**缺點：**
- 任務複雜度差異大
- 需要精確定義「乜係一個任務」

### 三、2026 年成功 AI Startup 的定價策略

#### 案例 1：Notion AI（加量不加價策略）

**策略：** 「加喺現有產品度，順便賣 AI」

**定價：**
- Notion Plus: $12/人/月 → 包含 AI
- Notion Business: $18/人/月 → 包含 AI + 更高limits

**關鍵洞察：**
```
唔好將 AI 當成獨立產品賣
將 AI 係做「現有產品既升級版」
客戶抵抗會低好多
```

**收入模型：**
- 唔增加 customer acquisition cost
- 現有客戶轉換率高
- 毛利率提升（因為 AI cost < 舊功能 cost）

---

#### 案例 2：Gamma（Output-based 策略）

**策略：** 按照「輸出價值」收費

**定價邏輯：**
```
$14/月：無限 PPT 生成
背後邏輯：幫用戶節省 $50-200/份既設計費用
一個月做 10 份就回本
```

**關鍵洞察：**
```
唔好sell「AI 幾犀利」
sell「幫你賺/省幾多錢」
```

---

#### 案例 3：Builder.io / Vercel（Consumption + Commitment）

**策略：** 「用幾多俾幾多 + 預付折扣」

**實際模型：**
```
Pay-as-you-go: 正常價
Monthly commitment: 8 折
Annual commitment: 6 折
```

**好處：**
- 獲取客戶：用量少既客戶
- 留住客戶：預付綁定
- 預測收入：知道幾多 guaranteed revenue

### 四、單位經濟學關鍵指標

#### AI SaaS 必追蹤指標：

| 指標 | 定義 | 目標值 |
|------|------|-------|
| **Gross Margin on AI** | (Revenue - AI Cost) / Revenue | >60% |
| **CAC Payback** | 幾耐回本 customer acquisition cost | <12 months |
| **AI Cost per Customer** | 每月 AI 運算成本 / 客戶數 | 監控趨勢 |
| **Revenue per AI Token** | 每 token 收入 vs 每 token 成本 | >3x |
| **Usage Retention** | 客戶係咪越用越多 | >130% NRR |

#### 常見問題：「點解我毛利咁低？」

```
情況：GPT-4o API $0.01/1K tokens
你收費：$0.015/1K tokens
毛利：50%

問題：你唔係卖緊 token，你賣緊「方便」同「功能」
但客戶可以直接用 API

解決方向：
1. 加好多 value-add（UI、分析、整合）
2. 走 value-based pricing
3. 走 vertical SaaS（律所/醫療/金融）
```

## 📊 2026 AI 定價趨勢總結

### ✅ 有效既策略：

1. **Hybrid 模型** — 固定訂閱 + usage 超額
2. **Value-based 定價** — 賣結果唔係賣功能
3. **加量不加價** — AI 係現有產品既升級
4. **Vertical focus** — 行業specific 定价能力更强
5. **Consumption commitment** — 預付折扣綁定客戶

### ❌ 失效既策略：

1. **純 token-based** — 毛利率太低
2. **無限用量** — 成本失控
3. **跟風定價** — 唔睇自己單位經濟
4. **得太便宜** — 「平」唔係 competitive advantage

## 🔑 關鍵takeaways

> **「2026 年 AI 成功關鍵唔係「做出AI」，而係「sell AI」。定價係最重要既 product decision。」**

1. **定價模型決定命運** — Token-based 毛利低，Value-based 先可以scalable
2. **Hybrid 係現階段最穩** — 固定收入 + cost coverage
3. **Vertical > Horizontal** — 行業specific 定價能力更強
4. **單位經濟學係生死線** — AI cost 係變動成本，要小心管理
5. **顧問服務係快速現金流** — 在建立自己產品既同時，可以用 consultancy 產生收入
