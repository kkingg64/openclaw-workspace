## 🔬 重点項目分析

### 1. Dagu (今日 Trending)
**Stars:** 4.7k+ | **語言:** Go

**簡介:** Local-first workflow engine，單一 binary 即可運行

**核心特色:**
- Zero-Ops: Single binary，under 128MB memory
- File-based storage — 無需 PostgreSQL/Redis
- Air-gapped Ready
- **Built-in LLM Agent**: 用自然語言創建/編輯 workflow
- 支持 19+ executors (HTTP, SQL, Docker, SSH, etc.)
- Cron scheduling + High Availability
- Git sync for DAG 版本管理
- **RBAC** (5 roles, OIDC, API keys)

**技術栈:**
- Go (single binary)
- YAML workflow definition
- Web UI included

**商業價值:** ⭐⭐⭐⭐⭐
- 極適合中小型團隊
- 可打包成 SaaS 提供
- AI Agent 內建呢個好強

### 2. Superlinked
**Stars:** 6.7k+ | **語言:** Python

**簡介:** AI Search & Recommendation Framework

**核心特色:**
- 結合 structured + unstructured data 入 vector
- 支持 text, images, numbers, categories, timestamps, recency
- Query-time weighting & dynamic parameters
- 支持多種 vector databases
- Self-hostable REST API server
- 可做 e-commerce search, semantic search

**技術栈:**
- Python
- sentence-transformers, open-clip
- In-memory 或 production vector DB

**商業價值:** ⭐⭐⭐⭐
- 適合做 AI應用既 search layer
- 可整合到自己既 AI Product
