### 🔥 焦點趨勢：Chrome DevTools MCP (今日 Hacker News Top 1)

#### 乜嘢係 Chrome DevTools MCP？

**功能：**
- 讓 AI Agent 直接控制瀏覽器 session
- Debug、自動化測試、網頁操作都可以用 natural language 完成

**意義：**
```
之前：AI → API → Backend
而家：AI → Browser → Frontend + UI Testing + Web Scraping
```

#### 點解呢個重要？

| 能力 | 之前 | 之後 |
|------|------|------|
| **Web Testing** | Selenium/Puppeteer script | "測試呢個 button click" |
| **Web Scraping** | Fixed selectors | Dynamic 理解頁面結構 |
| **UI Automation** | Hardcoded workflows | Natural language commands |
| **Bug Debugging** | Log 分析 | "幫我睇下 console error" |
