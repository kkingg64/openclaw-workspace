### Key Technical Learnings

**1. iPhone Safari CSS Bug — Root Causes & Fixes**
- **Bug**: iPhone Safari showed white background with lines (no dark theme)
- **Root Cause A**: `tw-animate-css` plugin incompatible with Tailwind v3 — caused build to produce incomplete CSS (only 3,933 bytes, no utility classes)
- **Root Cause B**: CSS variables were hex format (`#0a0c15`) but `hsl(var(--x))` syntax in Tailwind requires HSL format (`225 37% 6%`)
- **Fix**: Changed to `tailwindcss-animate` + converted all CSS variables to HSL format in `globals.css`
- **Result**: v27 — CSS now 44,576 bytes with full utility classes

**2. Login Error Messages — TC-102/103**
- **Bug**: Login error messages not displayed (used `alert()` instead of UI)
- **Fix**: Added error state with `useState` + styled `div` with `bg-destructive/10` class
- **Result**: v28 — Error messages now display properly with red styling

**3. Password Hash Corruption**
- **Bug**: fabio@madhorse.cloud password hash was corrupted (`$2a$` truncated to `b2/Lj3c...`)
- **Fix**: Re-hashed with `$2b$12$` prefix via direct SQL update
- **Verified**: `bcrypt.compare('admin123', hash)` now returns `true`

**4. Next.js 15 + Docker Build Issues**
- **Bug**: `clientReferenceManifest` invariant error on `/` route

- **Note**: Build corruption can happen silently — always check `.next/static/css/*.css` size after build

- Section: TC-906 External Links
- Added URL Validation Rule:
  - All external links MUST have **real, working URLs** (not placeholder)
  - Placeholder patterns that FAIL: `*example*`, `*#*`, `*/example`, `https://example.com/*`

- UI components showing "correct" content ≠ data is real

- "Looks real" is not sufficient — must check if links actually work

2. **API endpoint**: `GET /api/agents/sessions`
   - Read JSONL files from mounted volume
   - Parse `<thinking>` tags from transcript entries

3. **UI**: Agent thinking panel in Dashboard/Agents page
   - Real-time display of agent thinking

### Technical Note
