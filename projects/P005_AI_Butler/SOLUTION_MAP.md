## 🔑 核心功能

| 功能 | 說明 |
|------|------|
| **智能對話** | AI 自動回覆 WhatsApp 查詢 |
| **產品查詢** | RAG 搜尋產品資訊、價格、PV |
| **訂單管理** | 建立訂單、查詢狀態 |
| **獎金計算** | 根據職級計算獎金 |
| **權限管理** | Pioneer/Platinum/Founders 不同權限 |

## 🛠️ 技術堆疊

| 組件 | 技術 |
|------|------|
| AI 對話 | OpenClaw + MiniMax M2.5 |
| 工作流 | n8n (自託管) |
| 數據庫 | PostgreSQL + pgvector |
| 緩存 | Redis |
| WhatsApp | Green API (或 Business API) |
| 部署 | Mac Mini (本地) / 雲端 |

## 📱 用戶體驗

```
用戶發訊息到 WhatsApp
        │
        ▼
AI 自動識別意圖 (產品/訂單/獎金/查詢)
        │
        ▼
查詢知識庫 (如需要)
        │
        ▼
生成個人化回覆 (廣東話)
        │
        ▼
發送回覆到用戶 WhatsApp
```
