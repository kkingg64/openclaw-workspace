- [ ] 剪映（手機版）
- [ ] edge-tts（測試粵語配音）

### Step 3️⃣：測試配音
```bash
# 安裝 edge-tts
pip install edge-tts

# 測試粵語
edge-tts --voice "zh-HK-HiuGaaiNeural" --text "你今日用咗未？" --write-media test.mp3
```

### Step 4️⃣：寫第一個腳本
```
主題：「ChatGPT vs Claude 測評」
時長：45-60秒
結構：
1. Hook（前3秒）：「我用咗100個鐘測試 GPT-4o 同 Claude，先發現..."
2. Body：中間分享一個具體使用場景
3. CTA（結尾）：如果你鐘意，訂閱我
```

### Step 5️⃣：整第一條片
1. 用 ChatGPT 生成腳本
2. 用 edge-tts 生成粵語配音
3. 用剪映加字幕 + 畫面
4. 導出
