## 📋 任務背景

Fabio Corp 需要建立一個 **集中控制台 (Command Center Dashboard)**，整合三個核心功能：

1. **系統健康監控** — API、Docker、Gateway 狀態
2. **項目進度追蹤** — PROJECT_REGISTER.md 數據
3. **商業指標展示** — 收入、用戶、轉化率等

## 🔍 市場調研發現

### 行業標杆解決方案

| 解決方案 | 核心特點 | 適合規模 | 參考價值 |
|----------|----------|----------|----------|
| **Grafana** | 開源指標可視化，支持多數據源 | 中大型 | ⭐⭐⭐⭐⭐ |
| **Datadog** | 雲原生監控，APM + Logs + Metrics | 企業 | ⭐⭐⭐⭐ |
| **Linear** | 項目管理 Dashboard，強調 UX | Startup | ⭐⭐⭐⭐ |
| **Plane** | 開源項目管理，自托管 | 中型 | ⭐⭐⭐ |
| **Metabase** | 開源 BI 工具，簡易數據查詢 | SMB | ⭐⭐⭐⭐ |

### 競爭對手做法分析

**中小型 AI SaaS 公司常用方案：**
1. **自建 Dashboard** — 用 React/Vue + Grafana/Prometheus
2. **一體化平台** — 用 Linear/Jira + 自定義集成
3. **開源優先** — Grafana + Loki + Prometheus 堆疊

**趨勢：** 
- 單一面板 (Single Pane of Glass) 概念流行
- 實時數據更新 (WebSocket) 成為標配
- 移動端適配逐漸重要

## 🎯 必備功能清單 (Must-Have Features)

### 1. 系統健康監控模組

| 功能 | 優先度 | 描述 |
|------|--------|------|
| **API 狀態指示器** | 🔴 MUST | 顯示 MiniMax API 連接狀態 (正常/異常/超時) |
| **Docker 容器監控** | 🔴 MUST | 容器運行狀態、CPU、記憶體使用率 |
| **Gateway 狀態** | 🔴 MUST | OpenClaw Gateway 在線/離線 |
| **錯誤日誌流** | 🔴 SHOULD | 實時展示最近錯誤，方便快速定位 |
| **心跳檢測** | 🔴 SHOULD | 定時健康檢查，自動報警閾值 |

### 2. 項目進度追蹤模組

| 功能 | 優先度 | 描述 |
|------|--------|------|
| **項目狀態卡片** | 🔴 MUST | 顯示每個項目既狀態 (PROPOSED/IN_PROGRESS/COMPLETED) |
| **進度條** | 🔴 MUST | 可視化項目完成百分比 |
| **負責人標籤** | 🔴 MUST | 顯示項目負責人 (CEO/CTO/COO/CISO/CDO) |
| **到期日倒數** | 🔴 SHOULD | 顯示項目剩餘時間 |
| **里程碑標記** | 🟡 NICE | 關鍵節點高亮顯示 |

### 3. 商業指標模組

| 功能 | 優先度 | 描述 |
|------|--------|------|

| **用戶統計** | 🔴 MUST | 總用戶數、活躍用戶 (DAU/MAU) |
| **轉化漏斗** | 🟡 NICE | 註冊 → 激活 → 付費 轉化率 |
| **API 使用量** | 🔴 SHOULD | MiniMax API 調用次數/費用 |

### 4. 通用功能

| 功能 | 優先度 | 描述 |
