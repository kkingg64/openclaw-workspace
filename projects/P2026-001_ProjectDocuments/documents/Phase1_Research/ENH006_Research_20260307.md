## 🔍 調研發現

### 1. OpenClaw CLI Commands

```bash
# 取得所有 agents
openclaw agents list

# 取得 sessions (可 filter active minutes)
openclaw sessions --json
openclaw sessions --active 30 --json
```

### 2. 現有 API 狀態

- Gateway 運行中 (Port 18789)
- 默認無 HTTP API endpoints expose
- 需要啟用 `gateway.http.endpoints.chatCompletions` 先有 API

### 3. Vercel 限制

- Vercel 係 public cloud，唔可以直接訪問內部 VPS
- 需要 Bridge Service 中轉

---

## 🎯 解決方案

### Option A: Simple (推薦 Phase 1)

**Clock:**
- 改 `setInterval(updateTime, 1000)` 每秒更新
- 簡單直接的 code change

**Agent Status:**
- 使用 Next.js API Routes
- 服務器端調用 `openclaw agents list` + `openclaw sessions`
- 需要 Bridge Service (VPS)

### Option B: Full API

- 啟用 OpenClaw HTTP endpoint
- 完整既 OpenAI-compatible API
- 需要更多 configuration
