## 1. Clock UI Design

### 1.1 Current State
- Clock 更新頻率：30秒
- 格式：HH:MM:SS
- 問題：用戶感受到停滯

### 1.2 Proposed Design
| 項目 | 值 |
|------|-----|
| **更新頻率** | 1秒 (1000ms) |
| **格式** | HH:MM:SS |
| **字體** | Monospace (等寬字體) |
| **顏色** | Primary Accent (#22D3EE - Cyan) |
| **Animation** | Subtle pulse on second change |

### 1.3 Visual
```
┌─────────────────────────────┐
│ Last Updated: Loading...     │
│ 14:32:47  ← Live seconds   │
└─────────────────────────────┘
```

## 2. Agent Status Panel Design

### 2.1 Data Structure
```typescript
interface AgentStatus {
  id: string;           // e.g., "fabio-cto"
  name: string;        // e.g., "CTO"
  role: string;        // e.g., "Technology"
  status: "ACTIVE" | "IDLE" | "BUSY" | "ERROR";
  currentTask: string;
  lastActive: string;  // ISO timestamp
}
```

### 2.2 UI Layout
```
┌────────────────────────────────────────┐
│ 👥 Agent Status                        │
├────────────────────────────────────────┤
│ ● CTO        ACTIVE   Dashboard Eng   │
│ ● CISO       ACTIVE   Security Audit │
│ ○ COO        IDLE     Market Research│
│ ○ CDO        IDLE     UI Review      │
│ ● CEO        ACTIVE   Project Over.. │
└────────────────────────────────────────┘

Legend:
● = ACTIVE (green pulse)
○ = IDLE (gray)
⚡ = BUSY (orange)
✕ = ERROR (red)
```

### 2.3 Visual Style
| Element | Style |
|---------|-------|
| **Status Dot** | 10px circle with glow |
| **ACTIVE** | Green (#22c55e) + pulse animation |
| **IDLE** | Gray (#6b7280) |
| **BUSY** | Orange (#f59e0b) |
| **ERROR** | Red (#ef4444) |
| **Polling** | Every 30 seconds |
