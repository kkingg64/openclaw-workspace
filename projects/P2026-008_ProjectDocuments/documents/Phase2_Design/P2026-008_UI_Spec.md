> **⚠️ PLATFORM DATA ARCHITECTURE (Phase 3 MVP vs Future)**
> 
> | Platform | Phase 3 MVP | Phase 3.1+ |
> |----------|------------|-------------|
> | TikTok | **Mock data** (static JSON) | Live API via TikTok API / third-party aggregator |
> | 小紅書 (Xiaohongshu) | **Mock data** (static JSON) | Live API via Xiaohongshu unofficial API |

> | Twitter/X | **Mock data** (static JSON) | Live API via Twitter API v2 |
> | YouTube | **Mock data** (static JSON) | Live API via YouTube Data API v3 |
> 
> **Rationale:** Social media APIs require OAuth, rate limiting, and API approval. Phase 3 MVP uses realistic mock data to demonstrate UI/UX. Live APIs deferred to Phase 3.1 after CTO architecture review.

> **Data Refresh:** Mock data refreshes every 5 minutes (simulated). Live API mode uses 30-minute polling with caching.

## 9. Animation Specifications

### 9.1 Transition Timings

| Animation | Duration | Easing |
|-----------|----------|--------|
| Color change | 150ms | ease-out |
| Shadow change | 150ms | ease-out |
| Scale (hover) | 150ms | ease-out |
| Opacity fade | 200ms | ease-out |
| Collapse/expand | 200ms | ease-out |
| Modal open | 200ms | ease-out |
| Page transition | 300ms | ease-in-out |
| Carousel slide | 400ms | ease-in-out |

### 9.2 Loading Animations

| Element | Animation |
|---------|-----------|
| Skeleton | Shimmer: `translateX(-100%) to translateX(100%)` over 1.5s |
| Spinner | Rotate 360deg in 1s, linear, infinite |
| Progress bar (critical) | Pulse opacity 0.7-1 over 1s |
| Status dot (BUSY) | Pulse scale 1-1.2 over 1s |
