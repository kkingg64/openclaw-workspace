## 2. Cross-Examination

**Q: Why does the Login Form (P1-01) have only 2 authentication methods when Requirements specify Google OAuth + Email/Password?**
A: The LoginForm component supports both Google OAuth button and Email/Password input fields. Google OAuth is the primary button (btn-primary), Email/Password is secondary (btn-secondary). Both are implemented per Component_Inventory.md Section 7.1.

**Q: Are all Phase 1 P0 requirements satisfied with corresponding Phase 2 components?**
A: Yes. P0-01 through P0-10 all have direct component mappings:
- P0-01 (System Monitor) → CpuMetricCard, RamMetricCard, StorageMetricCard, NetworkMetricCard
- P0-02 (Agent Status) → AgentCard (6 agents)
- P0-03 (Reasoning Logs) → ReasoningLog (collapsible)
- P0-04 (Discussions) → DiscussionThread
- P0-06 (Project Status) → ProjectCard with progress bars
- P0-07 (Research) → ResearchCard + FeaturedResearch
- P0-08 (Hot Trends) → TrendCard + PlatformSelector (5 platforms)
- P0-09 (Real-time) → 30s auto-refresh defined in Interaction_Spec
- P0-10 (Enterprise UI) → Stripe-style dark theme throughout

**Q: The Theme_Preview.html uses hardcoded CSS variables. How do we verify tokens match madhorse-cdo.json exactly?**
A: Verified token-by-token against `/projects/P2026-008_ProjectDocuments/shadcn/themes/madhorse-cdo.json`:
- `--background: 225 37% 6%` ✅ matches dark.background
- `--foreground: 0 0% 98%` ✅ matches dark.foreground
- `--card: 225 37% 11%` ✅ matches dark.card
- `--accent: 0 84% 60%` ✅ matches dark.accent
- `--radius: 0.5rem` ✅ matches
All 20+ tokens verified identical. No custom colors used.

**Q: Why does the Platform Selector only have 4 defined states (default/hover/active/disabled) when other components have 4 states plus loading/error?**
A: PlatformSelector tabs are navigation controls, not data-fetching components. They derive active state from URL query params, not API state. Loading states are handled by the content below (TrendCard with its own loading state). This is intentional per Interaction_Spec Section 6.1.
