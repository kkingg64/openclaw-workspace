## 📋 1. 設計原則 (Design Principles)

### 核心原則
1. **簡約優先** - 「少則多」，首頁只show 最核心既野
2. **一click到位** - 用戶最重要既action一步完成
3. **廣東話優先** - 介面以廣東話為主，簡體英文為輔
4. **手機為主** - 80% 用戶體驗優化手機，但電腦都要靚

### 視覺風格 (Visual Style)
- **主色**: 溫暖橙 (#FF7043) - 代表家庭溫暖、食物
- **輔色**: 清新綠 (#4CAF50) - 代表健康、新鮮
- **字體**: Noto Sans TC (中文) + Inter (英文)
- **圓角**: 16px - 親和力既感覺
- **間距**: 8px grid system

## 🔄 2. User Flow (用戶流程)

### 主要流程圖

```
[打開App]
    │
    ▼
[首頁：今晚食咩？]
    │
    ├─ [一鍵生成建議] ──▶ [今日推薦：3道餸]
    │                           │
    │                           ▼
    │                    [睇詳細材料]
    │                           │
    │                           ▼
    │                    [生成購物清單]
    │                           │
    │                           ▼
    │                    [完成！save to list]
    │
    ├─ [自選偏好] ──────────────▶ [再生成]
    │
    └─ [Settings] ──────────────▶ [個人化設定]
```

### 用戶旅程 (User Journey)

| 步驟 | 畫面 | 用戶Action | 預期結果 |

| 1 | 首頁 | 一click「今晚食咩」 | 即刻show 3道餸 |

| 3 | 材料頁 | 睇材料 | 顯示購買清單 |
| 4 | 購物頁 | 生成清單 | 清單已ready |

## ⚙️ 5. 功能定義

### 核心功能 (Core Features)

| 功能 | 優先度 | 描述 |
|------|--------|------|
| 🔄 AI 建議 | 🔴 HIGH | 每次生成3道唔重覆既餸 |
| 🛒 購物清單 | 🔴 HIGH | 自動生成材料清單 |
| 🚫 避免重覆 | 🔴 HIGH | 同一星期內唔重覆建議 |
| ❤️ 收藏功能 | 🟡 MED | save低鍾意既餸 |
| 📊 歷史記錄 | 🟡 MED | 睇返之前煮過咩 |

### 額外功能 (Extra Features)

| 功能 | 優先度 | 描述 |
|------|--------|------|
| 📅 周計劃 | 🟢 LOW | 一次過生成一周既menu |
| 👪 家庭分享 | 🟢 LOW | share清單俾屋企人 |
| 🔔 提醒 | 🟢 LOW | 每日提醒諗今晚食咩 |
| 📊 營養數據 | 🟢 LOW | 卡路里/營養追踪 |
| 🎤 聲控輸入 | 🟢 LOW | 语音話「我想食清淡啲」 |

### 功能優先級矩陣

```
                    ┌──────────────┐
                    │   高價值     │
        收藏    ◀───┼──────────────┼───▶ AI建議
                    │              │
         周計劃    ◀───┼──────────────┼───▶ 購物清單
                    │   低價值     │
                    └──────────────┘
         低 Effort ─────────────────── 高 Effort
```

## 🎯 6. 交互設計 (Interaction Design)

### 動效 (Micro-interactions)

| 位置 | 動效 | 目的 |
|------|------|------|
| 生成按鈕 | 載入中轉圈 + 「緊係度諗緊...」 | 等待都有樂趣 |
| 結果出現 | Fade in + slide up | 自然過渡 |
| 剔低材料 | 划線 + 刪除線動畫 | 完成感 |
| 收藏 | 心仔跳動 + 填色 | 正面反饋 |

### 錯誤處理 (Error States)

- **冇網絡**: 「需要有網絡先用到，等你好快」
- **API失敗**: 「下次好啲，我哋会再試過」
- **冇合適既餸**: 「試多啲設定，或者聽日再試」
