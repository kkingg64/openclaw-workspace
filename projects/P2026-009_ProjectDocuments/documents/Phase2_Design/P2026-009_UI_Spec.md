## Design System

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-primary` | #09090b (zinc-950) | 主背景 |
| `--bg-surface` | #18181b (zinc-900) | Card/Panel 背景 |
| `--bg-elevated` | #27272a (zinc-800) | Hover/Active states |
| `--text-primary` | #fafafa (zinc-50) | 主文字 |
| `--text-secondary` | #a1a1aa (zinc-400) | 副文字 |
| `--accent-cyan` | #00F5FF | 主要強調色、準星、友方 |
| `--accent-magenta` | #FF00FF | 次要強調色、敵方標記 |
| `--accent-gold` | #FFD700 | Power-ups、獎勵 |
| `--danger` | #EF4444 | HP 低、敵方、錯誤 |
| `--success` | #22C55E | HP 滿、成功 |

| Usage | Font | Size | Weight |
|-------|------|------|--------|
| Game Title | Orbitron (Google Fonts) | 48px / 36px mobile | 700 |
| HUD Numbers | JetBrains Mono | 24px / 18px mobile | 600 |
| UI Text | Inter | 16px / 14px mobile | 400-600 |
| Button | Inter | 16px | 600 |

### Spacing
- 8pt grid system
- Game HUD margins: 16px from edges
- UI panels padding: 24px desktop / 16px mobile

## Component Spec

### Button Component
| Prop | Type | Default |
|------|------|---------|
| variant | `primary` / `secondary` / `ghost` | `primary` |
| size | `sm` / `md` / `lg` | `md` |
| glow | boolean | false |
| loading | boolean | false |

**States:** Default → Hover (scale 1.02, glow) → Active (scale 0.98) → Disabled (opacity 0.5) → Loading (spinner)

### HP Bar Component
| Prop | Type |
|------|------|
| value | number (0-100) |
| maxValue | number |
| showText | boolean |

**Thresholds:** >50% = cyan-green, 25-50% = yellow pulse, <25% = red fast pulse + screen vignette

### Room Card Component
| Prop | Type |
|------|------|
| name | string |
| players | number |
| maxPlayers | number |
| status | `open` / `full` / `in-progress` |

### Mini-Map Component
| Prop | Type |
|------|------|
| players | Array<{x, y, team}> |
| mapSize | number |
| currentPlayer | {x, y} |

## Animation Spec

| Trigger | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Page transition | Fade + slide up | 300ms | ease-out |
| Kill notification | Float up + fade | 1500ms | ease-out |
| Death screen | Desaturate + overlay | 500ms | ease-in |
| Button hover | Scale + glow | 150ms | ease-in-out |
| HP critical | Pulse + vignette | 800ms loop | ease-in-out |
| Score reveal | Stagger in from left | 200ms/row | spring |
