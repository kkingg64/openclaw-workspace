# Conventions

## Timezone (強制 HKT)

All timestamps must use HKT (UTC+8). Unmarked times are invalid.

| Context | Format |
|---------|--------|
| Timestamp | `2026-04-01 15:00 HKT` |
| Cron comment | `每日 HK 09:00 (即 UTC 01:00)` |
| Sign-off | `[CEO_SIGNED_2026-04-01_1500_HKT]` |

## Language

- Default: 廣東話 (Cantonese)
- Technical terms: Keep English (Docker, API, etc.)
- Tone: Direct, pragmatic, no bullshit
