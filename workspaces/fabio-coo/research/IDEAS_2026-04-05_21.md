## 💰 2026 Q2 定價模型紅黑榜

### ✅ 最成功嘅定價模式

#### 1) 成果定價 (Outcome-Based Pricing) ⭐⭐⭐⭐⭐
**定義：** 按實際成果收費，而非訂閱時間
**例子：**
- 「每份合同審查完成 $25」
- 「每月成功催收帳款嘅 15% 作為服務費」
- 「每個客戶查詢解決 $0.5」

**為何有效：** 客戶風險为零，只為成果付費。符合 「Pay for value」原則。

**實施難度：** 高。需要清楚定義「成果」並能量化。

#### 2) 用量定價 (Usage-Based) + 基價 ⭐⭐⭐⭐
**定義：** 每月有 base fee，再按實際使用量收費
**例子：**
- $99/月 base + $0.01 per agent task
- $299/月 base + $0.05 per document processed
- $999/月 base + $0.10 per customer interaction

**為何有效：** 降低客戶初期門檻，隨住佢哋用得多，收入自然增長。Alignment of incentives。

#### 3) 席位定價 + 功能分層 (Seat-Based Tiers) ⭐⭐⭐
**定義：** 按團隊人數收費，分 Starter / Pro / Enterprise
**例子：**
- Starter: $49/月 (3 seats, 100 tasks/month)
- Pro: $199/月 (10 seats, 1000 tasks/month)
- Enterprise: $599/月 (unlimited seats, unlimited tasks)

**為何有效：** 簡單易懂，Sales cycle 短。

---

### ❌ 失敗風險高嘅定價模式

| 模式 | 問題 | 案例 |
|------|------|------|
| 純按 seat 收費 | 客戶會 share accounts 規避 | Slack 早期問題 |
| 過高固定月費 | 客戶感知風險大，難以說服 | 大部分 AI startup 死亡原因 |
| 免費 + 付費增值 | 難以建立付費習慣 | 大部分 consumer AI 問題 |
| 純傭金模式 | 收入不穩定，難以預測 | 部分 ecommerce AI tools |

## 🔥 2026 Q2 新興 AI Agent SaaS 機會

### 機會 1: AI Contract Review Agent (法律科技)

**痛點：** 律師樓每日處理大量合同，律師費貴，但大量工作係重複性審查。

**方案：** AI Agent 自動審查合同，突出風險條款，提供修改建議。

**變現模型：**
```
┌─────────────────────────────────────────────────────────────┐
│  Pricing: $0.50 per page reviewed                          │
│  或: $499/月 unlimited reviews (for small firms)          │
│  或: Revenue share 5-10% of efficiency gains               │
│                                                             │
│  TAM: 全球法律服務市場 $850B+                              │
│  SAM: 合同審查細分市場 $25B+                               │
│  SOM: 首批目標 $10M ARR 絕對可達                         │
└─────────────────────────────────────────────────────────────┘
```

**關鍵成功因素：**
- 準確率 > 95%（需要人類律師覆核，但誤差要極低）
- 保密性合規（SOC2, HIPAA 若涉及醫療）
- 現有軟件整合（Clio, Practice Management software）

**關鍵成功因素：**

**痛點：** 收數公司請大量員工打電話/發信息催收，重複性極高。

**方案：** AI Agent 自動致電/發信息催收，識別付款承諾，自動安排還款計劃。

```
┌─────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────┘
```

**關鍵成功因素：**
- TCPA (電話消費者保護法) 合規
