### 1. 💎 Coding Agent Architecture — The Harness is the Moat

**Insight:** Sebastian Raschka 最新研究指出，2026 年 coding agent 嘅真正價值唔喺模型本身，而喺 harness（外層框架）。呢個發現徹底顛覆咗 "model-first" 嘅傳統思維。

**Core Finding — Model vs Harness:**
```
Vanilla LLMs (GPT-5.4, Opus 4.6, GLM-5) 能力接近
真正差異化因素：HARNESS

If you dropped GLM-5 into Claude Code's harness →
  likely perform on par with GPT-5.4 in Codex

Harness = 軟件 scaffold，負責：
- Prompt assembly + caching
- Tool exposure + execution
- File state tracking
- Permission management
- Memory + session resumption
```

**Coding Agent 六大核心組件 (Raschka's Mini Coding Agent):**
```
1. Live Repo Context (workspace context)
   → 自動探測 repo structure, branch, README

2. Prompt Shape + Cache Reuse  
   → Stable prefix (唔變) + Session state (常變)
   → 避免每次重建完整 prompt，慳成本

3. Structured Tools + Validation + Permissions
   → 預先定義 tools list，唔係 arbitrary command
   → 安全審批機制，防止執行危險操作

4. Context Reduction + Output Management
   → 防止 context overflow
   → 智能壓縮歷史記錄

5. Transcripts + Memory + Resumption
   → SessionStore 保存對話狀態
   → 中斷後可以繼續

6. Delegation + Bounded Subagents
   → 複雜任務拆解 → subagent 處理
```

### 2. 🔬 SLM (Small Language Models) — Edge AI 新戰場

**Insight:** GPT-5, Claude 4 這些大模型固然強，但 2026 年真正爆發嘅係 SLM 市場。細模型部署喺本地，無延遲、無數據外洩、慳成本。Apple on-device AI 就係最佳例子。
