### 2. 🤖 Agent-Native Architecture — SaaS 下一個十年範式轉移

```

│ ▸ 測試方法：隨便揀一個 UI action，問 agent 可唔可以做到             │
│ ▸ 例子：Jira → 某日 agent 可以完全替代，但 Linear 選擇兩者並行     │
└────────────────────────────────────────────────────────────────────┘

│ ▸ 改變行為 = 改 prompt，唔係改 code                                │
│ ▸ 例子：「Weekly Review」功能唔使寫代碼，只需要一行 prompt         │

├────────────────────────────────────────────────────────────────────┤

│ ▸ 有左 atomic tools + parity，新功能只需要寫新 prompt               │
│ ▸ Agent 可以做到你未預料到嘅事情                                   │
│ ▸ 用戶觀察模式 → 加入 domain tools → 重複                          │
│ ▸ 呢個係飛輪效應——越用越聰明                                      │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ 4️⃣ EMERGENT CAPABILITY — 未設計嘅功能自己浮現                     │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│ ▸ 唔需要為每個功能寫死代碼                                         │
│ ▸ 用戶需求 → agent 自動组合 tools 滿足 → 觀察模式 → 優化          │
│ ▸ 每一次 session 之後，下一次更容易                               │
│ ▸ AutoDream（Claude Code）：閒置時自動整理記憶，下一次更順        │
```
