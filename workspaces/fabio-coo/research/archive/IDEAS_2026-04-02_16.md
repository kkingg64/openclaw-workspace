### 2. 💰 2026 AI Agent 變現定價模式 — 傳統 SaaS 已死，新模式係王道

**Insight:** 傳統 per-seat SaaS 定價模式被 AI agents 徹底顛覆。**Agents 係 autonomous — 唔登入系統、24/7 運行、一個 agent 可以代替多個 human users**。結果：per-seat 定價完全唔合理。2026 年最新趨勢係 **outcome-based pricing**，Bloomberg 估計未來 10 年呢種模式會由 10% 升至 60%。

```
💰 2026 年 AI Agent 定價模式全面比較：

┌────────────────────────────────────────────────────────────────────┐
│ ❌ 傳統 Per-Seat Pricing — 已經死亡                               │
├────────────────────────────────────────────────────────────────────┤
▸ 問題：AI agent 唔需要 login、唔佔 seat、一個 agent做10個人工作    │
▸ 結果：客戶拒絕為「唔存在嘅 user」付錢                              │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ ✅ 模式 1: Usage-Based Pricing (最流行)                           │
├────────────────────────────────────────────────────────────────────┤
▸ 點收：per API call / per token / per minute                       │
▸ 優點：收入同使用量成正比、客戶風險低                               │
▸ 例子：$0.01/task、$0.10/1K tokens                                 │
▸ 適合：有自己 AI 能力、想控制 compute cost 嘅公司                   │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ ✅ 模式 2: Outcome-Based Pricing (價值定價) — 爆發中              │
├────────────────────────────────────────────────────────────────────┤
▸ 點收：當 agent 交付 конкретный результат 先收錢                   │
▸ 優點：vendor success = customer success，客戶覺得 fair            │
▸ 例子：per ticket resolved、per deal closed、per contract analyzed │
▸ Bloomberg 預測：10% → 60% adoption 未來 10 年                      │
▸ 適合：有明確 KPI 嘅垂直 SaaS                                      │
└────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────┐
│ ✅ 模式 3: Hybrid Model (2026 最佳實踐)                          │
├────────────────────────────────────────────────────────────────────┤
▸ 點收：Base subscription + Usage/Outcome overage                    │
▸ 例子：$500/month base（包含 1000 tasks）+ $0.5 per extra task     │
▸ 優點：predictable revenue + upside potential                      │
▸ 代表：Microsoft Copilot、Zendesk AI agents                         │
└────────────────────────────────────────────────────────────────────┘

📊 Salesforce Agentforce 案例研究：

▸ **$800M** annual revenue run rate，15 個月達成
▸ 關鍵：唔靠 per-seat，靠 agent 完成嘅工作收錢
▸ SaaStr 案例：Q1 2026 收入 > Q1 2025，但 sales staff 大幅減少
▸ 結論：**AI agents 係可以直接變現嘅**

💡 定價心理學：

▸ 唔好太低價：$9/month 顯示你唔知自己值幾多
▸ Anchor 高價：先 show $999/month plan，再推 $299/month「適合你」
▸ Enterprise 願意俾 10x 價錢買 2x 價值
▸ 最新趨勢：「幫你賺幾多」定價 → 「省幾多時間」定價
```

**💡 變現啟示：**
- **Outcome-based pricing** 係最大機會 —— 客戶願意俾錢因為睇到結果
- 一個幫你賺 $100K 嘅 agent，收 $10K/month 都抵
- Hybrid model 係最穩健 —— base fee 保底 + outcome bonus 獎勵
