## 🔍 Top Discoveries

### 1. 🧩 Prompt Engineering 2.0 — 從「指令」到「協作架構」

**Insight:** 2026 年嘅 prompt engineering 已唔再係「點寫 instruction」，而係「點設計 agent 行為架構」。兩者有本質分別。

**從 1.0 → 2.0 的進化：**

| 维度 | Prompt 1.0 (2023-2024) | Prompt 2.0 (2025-2026) |
|------|------------------------|------------------------|
| 焦點 | 指令清晰度 | 任務分解策略 |
| 設計 | 一次性 complete instruction | Iterative scaffold + fallback |
| 角色 | "Give me X" | "Here's context, reason through it" |
| 測試 | 單一 test case | Ensemble evaluation |
| 迭代 | 手動調優 | Auto-prompt optimization |

**為什麼呢個進化重要：**
- 複雜任務（research, analysis, writing）需要多個 intermediate steps
- 一次性 prompt 無法處理 unexpected edge cases
- Agent 需要知道「幾時問人」vs「自己繼續」

**Practical Prompt 2.0 Patterns:**

**a) Scaffold + Branch Prompting**
```
Role: Senior Research Analyst
Task: {input}
Constraints:
- If task requires <5 min, do it
- If requires >15 min, break into phases and ask for confirmation
- If ambiguous, list top 3 interpretations and ask

Output format:
- Phase 1: [what I'll do first]
- Phase 2: [contingent on Phase 1 result]
- Edge case handling: [how I'll deal with surprises]
```

**b) Explicit Confidence Signaling**
訓練 agent 知道幾時說 "I'm not sure" — 避免 hallucination + 提高 user trust。

**c) Context Scaffolding (唔係「乜都塞晒入去」)**
2026 年共識：唔係 context window 越大越好，而係：
- 給予「relevant context categories」而非全部細節
- 讓 agent 主動識別需要什麼，而非被動接收所有野

**商業價值：** Prompt engineering consulting 依家收費 US$150-500/hr，但多數人仍然用 1.0 方法。機會：build prompt templates for specific industries (legal, medical, finance) + sell as "prompt systems" not just "prompts"。

### 2. 👥 Human-Agent Collaboration Design — 點解呢個係 2026 年最被低估的技能

**Insight:** 太多人專注於「點樣automation更多野」，但忽略了「點樣設計 human-in-the-loop」。呢個係決定 agent 系統成敗的關鍵。

**核心問題：** 好多 AI agent 系統失敗，因為佢哋設計時假設人可以完全信任 agent output，但現實係：
- Agent 會犯錯（有時好confidence地犯錯）
- User 需要有意義的 oversight（唔係乜都撳同意）
- 太多 oversight = 慢咗；太少 oversight = 出事

**Human-Agent Collaboration Patterns 2026:**

**a) Adaptive Oversight (最適合香港/亞洲市場)**
根據任務風險程度動態調整 oversight level：
- Low risk (<$100,  reversible): Agent 自動執行，事後 report
- Medium risk ($100-10k, semi-reversible): Agent 提出建議，human 確認方向後執行
- High risk (>$10k, irreversible): Human approval required before each step

**b) Progressive Disclosure（唔係一次過show全部資訊）**
唔好一次性給 agent 大量 context：
- Phase 1: Agent gets minimal context, does initial reasoning
- Phase 2: Based on agent's questions, provide targeted context
- 避免 context overload，提高 agent 專門度

**c) Human-as-Checkpoint not Human-as-Bottleneck**
傳統 design: Human approves every step (bottleneck)
新 design: Human sets criteria, agent self-checks before executing

```
Example — Email Agent:
❌ Old: "Draft email → Human approves → Send"
✓ New: "Draft email → Agent checks: [tone=professional? recipient=correct? no hallucinations?] 
       → If all green: Send + Report 
       → If issues: Flag to human with specific concern"
```

**商業價值：**
- Human-agent collaboration design consulting — 幫企業重新設計佢哋的 AI workflows
- 培训团队點樣 effective oversight，而非「乜都accept」或「乜都要approve」
- ROI 好易計算：減少 oversight time 同時提高 quality

### 3. 🎯 Agent Skill: "Contextual Scaffolding" — 2026 年最有價值的 Prompt Skill

**Insight:** 2026 年最有價值的 agent skill 唔係「點樣寫 complex prompt」，而係「點樣用最少 context 做到最好效果」。

**呢個 skill 點解值錢：**
- Token 成本持續下降，但「知道用邊個 token」仍然稀有
- Context window 再大都有 limit（即使號稱 1M token）
- 直接影響 latency 和 cost

**Contextual Scaffolding 的具體方法：**

**a) Role-Based Context Injection**
唔係填塞 fact，而係建立「認知框架」：

```
Instead of: "Our company sells B2B SaaS to 50-200 employee businesses 
             in APAC region, we've been growing 30% YoY..."

Do this: "Role: You're advising a Series A B2B SaaS in APAC. 
          Strategic context: 30% YoY growth. 
          Key tension: scale vs quality.
          Ask me clarifying questions before advising."
```

**b) Constraint-First vs Content-First**
先告訴 agent 界限，後告訴佢目標：

```
Constraints first:
- Budget: $X
- Timeline: Y weeks
- Non-negotiables: [compliance, brand voice, etc.]

Then goals:
- Primary: [main objective]
- Secondary: [nice to have]
```

**c) Progressive Context Loading**
根據 agent 需求動態提供 context，而非一次性：

```python
# Pseudo-code pattern
def agent_loop(task):
    minimal_context = load_role_and_constraints()
```

**為香港/亞洲市場的機會：**
- 中小企業特别需要呢個 skill（預算有限，context management 直接影響 cost）
- 可以 build template library for APAC business contexts (談判風格, 文化差異, regulatory requirements)
