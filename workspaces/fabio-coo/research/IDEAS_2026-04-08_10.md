## 2. AI Agent 定價模型進化 — Outcome-Based 定價落地

### 傳統 SaaS 定價失效
Gartner 預測 **40% 的 agentic AI 项目在投產前就失敗**。原因不是技術，是經濟模型：

| 問題 | 說明 |
|------|------|
| **Token 成本失控** | 單一 user action 触发 10-50 次 LLM 調用；每個 retry 加倍開銷 |
| **Per-seat 失敗** | 一個安靜用戶 vs 一個 heavy user 造成 20x 成本差異 |
| **Per-task 失敗** | 任務顆粒度難以標準化，客戶容易爭議 |
| **Demo vs Production** | Demo 月費 $3-5K；Production 含 staging/monitoring/redundancy = $30-50K/月 |

### Outcome-Based 定價 — 2026 真正落地
**HighRadius 案例（2026-02）：**
- $0 實施費
- $0 訂閱費直到 go-live
- **只在實現 P&L 收益後收費**（按收益比例分成）

這是首個真正意義上的 outcome-based enterprise pricing for AI agents。

### 2026 定價模型光譜
1. **Credit-based** — 預购 credits 用完即止（靈活，適合 variable usage）
2. **Hybrid (Seat + Usage)** — 基礎 seat fee + 超出部分按量收費
3. **Outcome-Based** — 按實現價值收費（最高門檻，需要信任 + 可測量結果）
4. **Agentic Subscription** — 月費固定，但 agent 任務範圍受限（目前最常見掙扎模型）

### 💡 商業洞察
> **Micro-SaaS / 獨立創業者機會：** 複雜的 outcome-based 定價對大型企業有意義，但對於 SMB 或 indie hackers，**credit-based 或 hybrid** 更實際。重點是：**唔好學大廠玩免費，AI agent 成本結構唔允許**。
