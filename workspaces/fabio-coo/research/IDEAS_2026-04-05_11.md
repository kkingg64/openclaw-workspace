```

│         CLAUDE.MD 最佳實踐 2026                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📍 自動載入機制                                            │
│  ├─ 放喺專案 root 目錄                                     │
│  ├─ 每個 session 自動讀取                                 │

│  └─ 係 Claude Code 最重要嘅 context 文件                   │

│  📝 建議內容結構 (目標 < 200 lines)                         │

│  ├─ CODING STANDARDS — naming、formatting、conventions     │
│  ├─ KEY CONSTRAINTS — 用 "Never" / "Always" 強制定義       │
│  └─ TEAM/CLIENT INFO — consultancy 場景特別重要           │
│                                                             │
│  ⚡ 高級技巧                                                 │
│  ├─ 分層架構: global CLAUDE.md + project-level CLAUDE.md   │
│  ├─ 定期清理: 移除已完成專案、過時資訊                      │
│  ├─ 讓 Claude 幫手生成 initial 版本，再自己 review         │
│  └─ 使用時機: 大於 15 分鐘嘅任務用 Plan Mode               │
│                                                             │
│  🚀 CONTEXT 管理其他關鍵指令                                 │
│  ├─ /clear — 经常使用，分隔無關任務                        │
│  ├─ /simplify — 改善 generated code maintainability        │
│  ├─ /plan — 複雜任務先用 Plan Mode                        │
│  └─ claude --context-usage — 監察 token 消耗               │
└─────────────────────────────────────────────────────────────┘
```

**為何重要：**
- 沒有好的 CLAUDE.md = AI 每次都係新 project，浪費 context
- 係團隊用 AI 工具嘅基礎設施
- 係 Anthropic 官方推薦最佳實踐
