## 💡 商業機會分析

### 點做好 AI Agent Startup 融资pitch:

**Must-have elements (2026 investor expectations):**

```
1. ✅ Agentic AI first — 唔係 chatbot，係 autonomous agent
2. ✅ Vertical focus — 唔好話 "platform"，要話 "SaaS for X industry"
3. ✅ Clear path to $10M ARR — 唔好淨係講 TAM
4. ✅ Enterprise customers —唔少於 3 間 paying enterprise
5. ✅ Proprietary data / moat — 數據係護城河
6. ✅ ROI metric — 要具體 (如: "reduce cost by 40%")
```

**Red flags (2026 investors hate):**
```
❌ "AI-powered" (太多狼來了)
❌ Horizontal platform (競爭不過 Foundation Models)
❌ Burn rate > 70% of runway
❌ 淨係講 TAM size，唔講 market penetration
❌ 抄襲既 use case (customer service一大堆)
```
