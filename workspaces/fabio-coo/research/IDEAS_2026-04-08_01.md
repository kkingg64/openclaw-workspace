## 📊 CB Insights — 5 大 AI Agent 趨勢預測 2026

### 1. 多模態 AI Agents 赢得客戶服務搶地大戰

```
數據：
• 115+ 公司爭奪客戶服務 AI 市場（top 10 market by company count）
• 6間私營公司已做到 $100M+年收入
• 54% 市場玩家喺 2023 年後成立（AI-native）

點解語音係關鍵：
• 語音容忍 latency 低，無得甩帶
• 「Voice-first唔係關於音頻，係關於架構設計——
  interruption handling、barge-in、turn-taking logic」
  — PolyAI CEO

趨勢：由 channel coverage → multimodal performance
      即係唔再係「有冇做語音」，係「語音做得好唔好」
```

### 2. Voice AI 部署走向高觸碰（High-Touch）模式

```
信號：
• 供應商開始 embedded engineers on-site（驻场工程師）
• 由 developer-led → enterprise deployment
• 代表：Decagon（top 3% hiring）、Giga（top 6% hiring）

意義：
企業願意為語音 AI 付更多錢，因為佢哋要確保
million-scale calls 稳定运行
→ 高觸碰服務 = 更高 ARPU
```

### 3. Continuous Red Teaming 成為企業 AI 部署標準

```
信號：

呢個係個有新嘅 Agentic AI Defense 賽道
```

### 4. AI Agent Observability & Evaluation Tooling 成為 M&A 戰場

## 📊 SaaS × AI Agents — 2026 格局分析

### Deloitte 報告關鍵洞察

```
定價模式演變：

傳統：Per-user/month subscription（已够）
新興：Outcome-based / Value-based pricing

點解難做：
• 需要定義清楚乜嘢係 "an agent," "a task," 
  "a process," "an interaction," "an outcome"
• Multi-agent systems（多個 vendor agents）點計 value？
• 收入變得 unpredictable

企業準備工作：
1. 投資 data management（同 AI agents 數據打通）
2. 接受複雜性（多 models、multi-vendor）
3. 準備混合定價模型
4. 培訓員工做 "AI orchestrator"

信號：企業 customers 已經開始問呢啲問題
      供應商需要準備好答案
```

## 🔥 Top 3 洞察

### 1. 醫療行政 AI 係最大資金藍海（Hippocratic AI、EliseAI 模式）

```
數據：
• 美國醫療行政成本：$6000 億/年
• 地產管理員工流動率：40%+
• Hippocratic AI：$402M 融资，$3.5B 估值
• EliseAI：$392M 融资，$2.2B 估值

點解work：
• 護士/行政人員嚴重短缺
• AI 處理 inbound calls、預約、跟進、保險查詢
• 唔係取代醫生，係處理行政

機會：
將呢個模式搬去其他高行政成本領域
牙科、眼科、法律、會計——全部有類似痛點
```

### 2. AI Agent Control Center / Orchestration Layer 係下一個必爭之地

```
Deloitte 預言：
• Stand-alone SaaS apps 會係主要 interaction layer
• 但係會有 third-party "control centers"
  （類似而家嘅 SaaS management platforms）
• 功能：跨 vendor agents 嘅 usage tracking、cost、access、
  performance、security、compliance

信號：
企業唔想被單一 vendor lock-in
佢哋想要：
1. 統一睇法（single pane of glass）
2. 跨 vendor agents 協調
3. 審計 + 合規追蹤

機會：
幫企業管理 AI agent 複雜性——
呢個係基础设施層面，唔會被單一 AI model 取代
```

### 3. AI Security / Agentic AI Defense 處於早期資金階段，窗口期開放

```
數據：
• $3.6B 已流入 AI 安全 startup
• RSAC 2026 一周：$392M 宣佈
• MCP security funding：$40M disclosed

信號：
• 企業級 AI agents 普及 → 安全問題爆發
• 傳統 security tools 唔夠用（需要為 AI agents 特製）
• Continuous red teaming 成為企業標準要求

建議：
呢個係少數仲處於早期嘅 AI Agent 細分市場
如果進場做 tooling，依家仲係窗口期
```
