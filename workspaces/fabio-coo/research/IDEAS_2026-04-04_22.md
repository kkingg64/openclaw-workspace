## 🔄 MCP Skills 包裝方法論

**從 MCP Tool → Sellable Skill 的 5 步公式：**

```
Step 1: 識別高頻痛點
  └→ 查看 MCP 商店評論、Reddit、Twitter 怨言
  └→ 找 "I wish there was a way to automate X"

Step 2: 選擇合適的 MCP 工具組合
  └→ 通常 3-5 個相關 tools 包裝成 1 個 workflow
  └→ 例如：GitHub + Linear + Slack = Sprint Retrospective Skill

Step 3: 定義輸入/輸出標準
  └→ 輸入：用戶提供什麼？（task description, dates, team name）
  └→ 輸出：AI 生成什麼？（report, summary, action items）
  └→ 成功標準：測量結果可量化

Step 4: 包裝成 Claude Code Skill / Cursor Rule / MCP Server
  └→ Claude Code: .claude/commands/ 目錄
  └→ Cursor: .cursor/rules/ 目錄
  └→ MCP Server: smithery.ai 或自架

Step 5: 選擇變現模式
  └→ freemium：基本版免費，高級版 $19/mo
  └→ per-call：$0.01-0.10 每執行
  └→ subscription：$29/mo 無限量
```
