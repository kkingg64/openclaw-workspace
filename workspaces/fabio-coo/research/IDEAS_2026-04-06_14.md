### 5. 💰 SaaS 生死戰 — 三個關鍵趨勢

**1. 從「Seat 定價」到「Usage 定價」**
- AI Agent唔再需要seat——一個Agent可以替代多個用戶
- Workday、Salesforce、Adobe 等以 seat 為基礎嘅 SaaS 最受打擊
- 2026 年将加速轉向 consumption-based / outcome-based 定價

**2. Agent 正在「使用」SaaS，唔係「取代」**
- Fortune 分析：AI agents aren't eating SaaS—they're using it
- Agent 仍需要調用 API 完成任務，SaaS 變成底層數據源
- 但呢種「被使用」關係令 SaaS 廠商失去定價權

**3. 「看不見的 SaaS」興起**
- AI Agent 直接完成任務，用戶唔再需要睇 UI
- Deloitte：「Invisible SaaS」——軟件變成幕後基礎設施
- 對開發者係機會，對唔轉型嘅傳統 SaaS 係威脅
