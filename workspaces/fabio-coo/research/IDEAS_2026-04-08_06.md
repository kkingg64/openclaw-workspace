## 🔥 SaaSpocalypse — 危機分析

### 咩係 SaaSpocalypse？

```
2026年2月，美國 SaaS 市場暴跌：
• $285-300B 蒸發（單月記錄）
• Salesforce、Workday、DocuSign、Adobe 被大幅降級
• 法律 SaaS（LegalZoom -19.68%）、新聞（Thomson Reuters -15.83%）
  成為重災區

核心問題：AI Agents 可以代替人類操作軟件
→ per-seat 收費邏輯根本站不住腳
→ 市場重新諗：軟件值幾多係用結果衡量，唔係人頭
```

### 傳統 SaaS 定價模型正在被顛覆

| 舊模型 | 新模型 |
|--------|--------|
| Per-seat（每人幾多錢） | Per-action / Per-task（每個動作收費） |
| 人力成本替代 | 結果交付導向 |
| 固定功能 | AI 自主適配 |
| 軟件即工具 | 軟件即服務（真正嘅 service） |

```
Deloitte 預測：
• 2030 年，40% Enterprise SaaS 開支將移向 usage-/agent-/outcome-based 定價
• Gartner：2026年底，40% enterprise apps 將嵌入 task-specific AI agents
• Microsoft 策略：Copilot bundling → 現有 subscription 度加 AI，同時加價

結論：SaaS 老大哥們已经开始夹硬转型，但系动作慢紧你就执输
```

## 🤖 AI Agent 框架大戰 — 2026 生態地圖

### 主要玩家

```
OpenAI Agents SDK
• 定位：Enterprise 首選
• 優勢：GPT-4o 整合，生態系統成熟
• 弱點：Vendor lock-in 風險高

Anthropic MCP (Model Context Protocol)
• 定位：Open standard，生態系統建設者
• 優勢：唔綁邊個 model，靈活性高
• 弱點：成熟度比 OpenAI 差少少

Google ADK (Agent Development Kit)
• 定位：Google 生態用家
• 優勢：Vertex AI 整合，Gemini 模型
• 弱點：生態相對封閉

LangGraph / LangChain
• 定位：研究 / 複雜 workflow
• 優勢：靈活性極高，community 大
• 弱點：Production ready 度被質疑

CrewAI
• 定位：Multi-agent 協作
• 優勢：易用，適合 team-based agents
• 弱點：企業級功能落後

Pydantic AI
• 定位：Type-safe agent 開發
• 優勢：modern Python DX
• 弱點：相對新

Smolagents
• 定位：Lightweight，embedded agents
• 優勢：夠晒輕，適合資源有限場景
• 弱點：功能有限
```

### MCP vs OpenAI — 生態之爭

```
MCP (Model Context Protocol) 係 Anthropic 推出嘅 open standard
→ 目標：任何 AI model 可以用任何工具
→ 類似 USB-C：統一接口，生態互聯

OpenAI Agents SDK 係 proprietary
→ 目標：用 OpenAI 模型嘅最佳體驗
→ 類似 Apple 生態：控制成個 stack

趨勢信號：
• 越來越多 developer 傾向 MCP，因為怕被 vendor lock-in
• 但 OpenAI 生態依然係 enterprise 主流選擇
•最終邊個贏：睇邊個建立起更強嘅工具生態
```

## 🎯 市場缺口 × 機會分析

### 被忽視嘅垂直領域

```
1. 教育科技（EdTech）AI Agents
   • 現狀：ChatGPT 被當作代做功課工具，無專門 agents
   • 缺口：Personalized learning paths、automated tutoring、grading
   • 潛力：全球 EdTech 市場 $404B，但 AI 滲透率極低

2. 建築 / 地產 AI Agents
   • 現狀：大量 admin work（報價、進度追蹤、法規合規）
   • 缺口：Project management agents、permitting automation
   • 潛力：地產科技開始升溫，監管復雜幫助護城河

3. 農業供應鏈 AI Agents
   • 現狀：極少人做，供應鏈極度分散
   • 缺口：Procurement、logistics、weather-based decision making
   • 潛力：全球農業市場夠大 tech 滲透率極低

4. 中小企財務 AI Agents
   • 現狀：Bookkeeping、tax、payroll 仲係人手為主
   • 缺口：SMB-focused accounting agents
   • 潛力：市場夠大，切入點明確
```

### 定價模式創新機會

```
舊模式：Per-seat、per-month
新機會：

1. Outcome-based pricing
   → 根據幫客戶賺 / 慳幾多錢收費
   → 例如：幫外賣店提升 20% 回頭客，收增量收入 10%

2. Usage-based AI agent pricing
   → 按任務完成量收費
   → 類似 AWS，但係 for AI agents

3. Agent marketplace + rev share
   → 建立平台，撮合 agent 開發者 + 企業客戶
   → 收撮合費 + 成功費

4. Vertical SaaS + AI agent bundle
   → 唔再卖 seat，改卖 AI employee
   → 例如：地產 agents，包辨公室行政管理所有野
```
