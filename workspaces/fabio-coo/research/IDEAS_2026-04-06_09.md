### 3. Claude Code Agent Teams vs Subagents vs Hooks

**Agent Teams（團隊協作）：**
- 多個 Claude Code instances 共同合作
- Team Lead 負責任務協調分配，Teammates 獨立運作
- 通過共享 task list 和「mailbox system」通信
- 適合複雜項目並行處理（UX、技術架構、關鍵分析）
- ⚠️ Token 消耗大（每個 teammate 維持完整 context window）

**Subagents（子代理）：**
- 主 agent 派生的專業 AI 助手，隔離 context window
- 內建 subagents：Explore、Plan、general-purpose
- 可自定義 subagents（代碼審查、文檔生成等）
- 適合並行處理複雜任務
- 比 Agent Teams 更節省 token

**Hooks（鈎子機制）：**
- 類似 Git hooks，15 種生命週期事件可觸發自定義處理
- 三種鈎子類型：
  - **Command：** 運行 shell 命令
  - **HTTP：** 發送 event data 到 URL
  - **Prompt：** 單輪 LLM 評估做決策
- 用途：自動代碼格式化、阻擋危險命令、發送通知、強制項目規則
- **確定性控制**——不同於 prompt 規則，model 無法忽略

**💡 變現機會：**
- Hook Templates Marketplace（預設鈎子組合）
- Subagent 技能包（代碼審查、測試生成、文檔自動化）
- Agent Team 協調服務
