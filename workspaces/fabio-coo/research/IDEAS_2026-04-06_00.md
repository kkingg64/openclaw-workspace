## 📊 市場洞察

### 1. MCP (Model Context Protocol) 生態爆發中

MCP 係 2024-2025 年興起嘅標準，旨在成為 AI 應用嘅「USB-C」——統一 AI 系統連接外部工具同數據嘅方式。

**關鍵撐撐：**
- **支援嘅客戶端：** Claude、ChatGPT、VS Code、Cursor、Windsurf、Augment、Claude Code、Rime 等
- **應用場景：** calendar、Notion、文件系統、數據庫、3D 打印、搜尋引擎、Figma
- **官方伺服器生態：** 高達 1,000+  community-contributed servers（MCP 官方 repository）

**商業價值：**
- MCP 令 AI Agent 開發成本大幅下降——一個 server 可用於所有支援 MCP 嘅客戶端
- 企業可自建 MCP 伺服器，安全地將內部數據連接 AI
- 標準化意味著「MCP as a Service」嘅商機——幫企業建立、部署、管理 MCP 伺服器

### 2. Cursor IDE — Agent Skills 變現最前線

Cursor 係目前最具體變現能力嘅 AI coding 工具，佢嘅skills 生態提供明確嘅商業模式。

**Skills 變現機制：**
- Cursor 支援社區創建嘅 custom instructions / prompts（稱為 "Cursor Rules" 或 "Skills"）
- 成功嘅 skills 可以通过 GitHub 托管 + Gumroad / LemonSqueezy 銷售
- 熱門 category：Web Dev、Data Science、DevOps、Security、Mobile Development

**市場信號：**
- 大量付費 skills 出現在 Gumroad（$5-$50/個）
- 獨立開發者月收入可達 $1,000-$10,000+
- Cursor Rules Marketplace 開始形成

**機會：**
- 中文/粵語市場幾乎空白——針對華人開發者嘅專業 skills
- 行業垂直 skills（金融、醫療、電商）高價值但少人做
- "從零到一" 教學 + 配套 skills 捆綁銷售

### 3. Claude Code / Windsurf / Augment — 企業級 Agent 技能需求

企業採用 AI coding agent 嘅障礙唔係技術，而係「點樣定制度化使用政策」。

**痛點：**
- 安全同合規（代碼審查、數據私隱）
- 現有 tools 整合（Jira、Confluence、GitHub Enterprise）
- 輸出質量控制

**機會：**
- Agent governance / compliance frameworks（顧問服務）
- 企業內部 MCP 伺服器部署
- AI coding policy templates（中型企業適用）
- 垂直行業嘅 AI coding guidelines（醫療、金融、的法律合規）

---

### 4. OpenClaw — 自主 AI Agent 平台嘅差異化

OpenClaw 係一個有別於 Cursor/Claude Code 嘅定位——面向 personal AI agents 而非祇係 coding。

**差異化觀察：**
- OpenClaw 支援 custom skills、記憶系統、連接各種工具（browser、nodes、messaging）
- 佢嘅 tool ecosystem 似 MCP 但係更面向 C端（個人用戶）
- Agents 可以係 stand-alone service 或 paired with nodes（物聯網場景）

**變現機會：**
- OpenClaw Skills Marketplace（如果有嘅話）
- 針對 OpenClaw 嘅 custom agents 開發服務
- OpenClaw agent templates for specific use cases（電商運營、行政助理、內容創作）
