### 2. 40% AI Agent 項目將於 2027 年被放棄——點解？

Gartner 預測：過半 AI agent 項目將失敗，但唔係因為模型能力不足。

**五大落地障礙：**

| 障礙 | 問題 | 解決方向 |
|------|------|---------|
| **1. Pilot-ware** | demo 勁，但 production 穩定性 zero | 從第一天開始工程化設計 |
| **2. 數據整合摩擦** | ERP、CRM、ITS 碎片化，agent 無法落地 | 標準化 MCP/iPaaS 整合層 |
| **3. 風險治理** | prompt injection、over-permissioned agents | Least-privilege + audit trail |
| **4. 長週期工作流可靠性** | 小錯誤率喺多步流程中累積爆炸 | Deterministic checkpoints + human-in-the-loop |
| **5. ROI 模糊** | 為展示而設計，唔係為業務價值 | 從結果倒推，唔係從技術向前推 |

**💡 商業機會：** 幫企業解決呢 5 個障礙 = 巨大嘅顧問 + 工具市場

### 3. 企業決策者真正想要乜嘢——從 hype 到 execution

**改變思維方式：**
- ❌ 「AI 可以做幾犀利嘅 demo？」
- ✅ 「我可以安全、可衡量、可重複咁改善邊個流程？」

**成功企業點做：**
1. 集中做 2-3 個高價值、生產級應用案例，唔係幾十個 pilot
2. Deterministic steps（規則、API、系統檢查）+ Agent reasoning 混合
3. Identity、least-privilege、audit logs、explainability 從 day 1 設計
4. 從 model metrics 轉向 business metrics

**CIO 信任範圍（目前已批准）：**
- 數據收集同驗證
- 工作路由同優先級排序
- 建議草稿 + 下一步行動
- 定義邊界內跨系統任務協調

**未批准（仍需 human-in-the-loop）：**
- 高風險財務審批
- 客戶/患者敏感資料處理
- 法律合規決策

**📌 機會：做「Agent Governance & Reliability」嘅白牌工具——呢個缺口極度匱乏**

### 4. AI Agent 顛覆 SaaS 嘅具體方向

**已被顛覆嘅 SaaS 類別（按風險排序）：**

| 高風險（被取代中） | 中風險（正在整合） | 低風險（短期安全） |
|-----------------|-----------------|-----------------|
| 客戶服務（chatbot → 自主 agent） | 市場營銷工具（sequence → 自主部門） | 高度個性化 creative tools |
| 銷售 automation（lead gen → 自主 agent） | BI/Analytics（query → 自然語言） | 協作/文檔工具 |
| IT service management（ticket → 自主 IT） | HR onboarding（手動 → 自動化） | 數據庫/基礎架構 |

**💰 關鍵商業模式轉變：**
- 舊：Seat-based pricing（按人头收費）
- 新：**Pay-per-resolution** / Outcome-based pricing（按結果收費）
- 呢個改變對軟件公司收入模式係顛覆性嘅
