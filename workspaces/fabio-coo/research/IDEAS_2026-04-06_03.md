### 2. MCP 生態——「USB-C for AI」嘅爆發期

**MCP 係咩：**
Model Context Protocol 係連接 AI agents 與外部工具/數據嘅開放標準。等於話：
- 開發者寫一次 MCP server → 所有支援 MCP 嘅 AI 工具都用得
- 生態正在瘋狂膨脹

**2026 Q1 MCP 生態關鍵數據：**

- Cursor、VSCodium、Claude Desktop、OpenClaw 已全部支援

### 4. Cursor + OpenClaw Skills 生態觀察

**Cursor 熱門 Agents/Skills 模式：**

- **Beta: Daily Code Review** — 每日自動review昨日嘅PR

**OpenClaw Skills 特色：**
- 以 task 為中心嘅 skill 封裝

**💡 OpenClaw 差異化機會：**

### 6. 「技能即產品」嘅新商業模式

**概念驗證：**
把專業領域知識封裝成可執行的 agent skill，用戶付費解鎖。

**可行方向：**

**方向 A：「Figma to Code」Skill**
- 輸入：Figma file link
- 輸出：Production-ready React/Next.js code
- 變現：Credit-based（每次使用扣credit）
- 類似：Framer AI, Builder.io

**方向 B：「Startup MVP Builder」**
- 輸入：Product brief（1-2句話描述）
- 輸出：Full-stack MVP code（auth, database, basic UI）
- 目標用戶：非技術 founder、side project 愛好者
- 變現：SaaS subscription

**方向 C：「Compliance Checker」**
- 輸入：公司代碼庫 + 行業標準（HIPAA/GDPR/PCI）
- 輸出：合規報告 + 修復建議
- 變現：企業 licence
