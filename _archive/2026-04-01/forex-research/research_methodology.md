## 2. 分析框架

### 2.1 技術分析指標體系

#### 趨勢指標 (Trend Indicators)

| 指標 | 參數 | 用途 | 信號解讀 |
|------|------|------|----------|
| **SMA (Simple Moving Average)** | 20, 50, 200 期 | 判斷趨勢方向 | 價格 > 上均線 = 上升趨勢 |
| **EMA (Exponential Moving Average)** | 12, 26 期 | 對價格變化更敏感 | 用於短期趨勢判斷 |
| **Bollinger Bands** | 20, 2 | 判斷超買超賣 | 價格觸及上限 = 超買；觸及下限 = 超賣 |

#### 動量指標 (Momentum Indicators)

| 指標 | 參數 | 用途 | 信號解讀 |
|------|------|------|----------|
| **RSI (Relative Strength Index)** | 14 期 | 衡量價格變動速度 | RSI > 70 = 超買；RSI < 30 = 超賣 |
| **MACD** | 12, 26, 9 | 判斷趨勢反轉 | MACD 金叉 = 買入；死叉 = 賣出 |
| **Stochastic Oscillator** | 14, 3, 3 | 判斷潛在反轉點 | %K > %D = 買入信號 |

#### 支撐/阻力位

| 指標 | 用途 |
|------|------|
| **Fibonacci Retracement** | 識別潛在反彈/回調位 (23.6%, 38.2%, 50%, 61.8%) |
| **Pivot Points** | 日內支撐與阻力位 |
| **Horizontal Support/Resistance** | 歷史高低點 |

### 2.2 基本面分析框架

#### 宏觀經濟因素

| 因素 | 指標 | 數據來源 | 影響方向 |
|------|------|----------|----------|
| **利率** | 各國央行利率決策 | Forex Factory, Bloomberg | 利率上升 = 貨幣升值預期 |
| **GDP** | 各國GDP增長率 | Trading Economics, World Bank | GDP上升 = 貨幣強勢 |
| **通脹** | CPI, PPI | Trading Economics | 高通脹 = 央行加息預期 |
| **就業** | 非農就業數據 (NFP) | Forex Factory | 就業強 = 美元強 |
| **貿易平衡** | 進出口數據 | 各國統計局 | 順差 = 貨幣升值 |
| **投資者情緒** | VIX 波動率指數 | CBOE | 避險情緒升 = 黃金、日元升值 |

#### 貨幣政策因素

| 因素 | 關注點 |
|------|--------|
| **Fed (美聯儲)** | 利率決策、量化寬鬆/收緊、褐皮書 |
| **ECB (歐央行)** | 利率決策、資產購買計劃 |
| **BOJ (日本央行)** | 負利率政策、收益率曲線控制 |
| **HKMA (香港金管局)** | 聯繫匯率制度、資金流動 |

#### 商品特有因素

| 商品 | 關鍵因素 |
|------|----------|
| **黃金** | 美元走勢、實際利率、通脹預期、地緣政治 |
| **白銀** | 黃金比率、工業需求（電子、太陽能） |
| **原油** | OPEC+減產決定、庫存數據、全球需求 |
| **天然氣** | 天氣預報、庫存、冬季/夏季需求 |
| **銅** | 全球經濟景氣、中國需求、基建投資 |
| **穀物** | 天氣、USDA報告、貿易政策、運輸成本 |

### 2.3 分析決策矩陣

```
                    技術面                    基本面
                    ─────                    ─────
信號一致              ✅ 強烈建議執行          ✅ 順勢而為
技術面買訊 + 基本面中性   ⚠️ 審慎執行             ⚠️ 小注試單
技術面中性 + 基本面利多   📊 觀察為主             📈 中期部署
信號衝突              ❌ 唔好做                ❌ 等待明確
```

## 4. 風險評估方法

### 4.1 風險評估框架

#### 風險等級分類

| 等級 | 定義 | 建議行動 |
|------|------|----------|
| **🟢 低風險** | 技術面 + 基本面一致，順勢交易 | 正常部署 |
| **🟡 中等風險** | 信號模糊或衝突 | 小注試單、收窄止蝕 |
| **🔴 高風險** | 重大事件前後、波動異常 | 建議唔好做、觀望為主 |

#### 技術面風險信號

| 信號 | 風險意義 |
|------|----------|
| 價格觸及 Bollinger Band 極端 | 可能有回調風險 |
| RSI > 80 或 < 20 | 超買/超賣嚴重 |
| 價格橫行突破失敗 (False Breakout) | 假突破風險高 |
| 成交量異常放大但價格停滞 | 可能逆轉 |

#### 基本面風險信號

| 信號 | 風險意義 |
|------|----------|
| 央行會議前一日 | 避免新倉 |
| 重大地緣政治事件 | 波動加劇、難以預測 |
| 經濟數據預期與實際差距大 | 可能出現大幅波動 |
| 流動性極低時段（節假日） | 點差擴大、價格跳空 |

### 4.2 止蝕止盈規則

| 規則 | 說明 |
|------|------|
| **止蝕 (Stop Loss)** | 每筆交易最大虧損 ≤ 2% 賬戶 |
| **風險回報比 (Risk:Reward)** | 至少 1:2 才執行 |
| **止盈 (Take Profit)** | 根據技術位設置，至少 1:2 風險回報比 |
| **移動止蝕** | 當盈利達到 1:1 時，將止蝕移至成本價 |

### 4.3 幾時應該建議「唔好做」

| 情況 | 原因 |
|------|------|
| 🔴 缺乏清晰信號 | 技術面同基本面矛盾 |
| 🔴 重大事件前夕 | 央行議息、GDP公佈等 |
| 🔴 波動率過高 | VIX > 25，或預期有重大事件 |
| 🔴 流動性不足 | 節假日、深夜時段 |
| 🔴 之前連續虧損 | 需要冷靜期，避免報復性交易 |
| 🔴 未能設置合理止蝕 | 技術位不明確 |

## 5. 匯報格式

### 5.1 每日簡報模板

```markdown
## 📈 每日市場簡報 [日期]

### 🎯 焦點品種
- [品種1]: [主要觀點]
- [品種2]: [主要觀點]

### 📊 技術分析
| 品種 | 趨勢 | 關鍵位 | 指標信號 |
|------|------|--------|----------|
| EUR/USD | 上升/下降/區間 | 支撐1.0800 / 阻力1.1000 | RSI 55, MACD 金叉 |

### 📰 基本面要聞
- [事件1]: [影響分析]
- [事件2]: [影響分析]

### ⚠️ 風險評估
- [品種]: 🟢低風險 / 🟡中等 / 🔴高風險
- 原因: [說明]

### 💡 建議
| 品種 | 行動 | 進場價 | 止蝕 | 目標 | 風險回報比 |
|------|------|--------|------|------|------------|
| EUR/USD | 買入/賣出/觀望 | 1.0900 | 1.0850 | 1.1000 | 1:2 |

---
**下次更新:** [時間]
```

## 6. 附加指引

### 6.1 禁止事項 (來自 SOUL.md)

- ❌ 唔好叫老闆「趁低吸納」
- ❌ 唔好保證賺錢
- ❌ 唔好追單 (martingale)
- ❌ 唔好溝淡

### 6.2 核心原則

1. **Analysis first, then action.** - 先分析，後行動
2. **Risk first** - 永遠諗住輸緊既時候點算
3. **Data-driven** - 用 evidence 唔好用感覺
4. **如果唔sure，寧願唔做** - 寧可錯過，唔好做錯
