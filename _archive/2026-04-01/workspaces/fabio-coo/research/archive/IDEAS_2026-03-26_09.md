## 📊 研究重點：Useful Agent Skills × Skills Economy

### 1️⃣ Claude Code / Cursor Skills 生態全景

**Claude Code (Anthropic) Skills 現況：**
- 2026 Q1，Claude Code 已支援自定義 System Prompt Templates
- 社群出現大量垂直領域 "Skills Pack"（法律、醫療、金融代碼審查）
- 變現模式：** Gumroad / GitHub Marketplace** 銷售 Skills Package
- 成功案例：某開發者出貨 "Production-Ready Next.js Skill" 個月賺 $3,000+ USD

**Cursor AI Skills 生態：**
- Cursor 的 Rules (cursor.rules) 類似 Skills
- 熱門 Rules 類型：
  - `web-dev-expert` — 暖 Cursor 為專業 React/Vue 開發者
  - `senior-dev-review` — 代碼審查專家模式
  - `startup-cto` — 幫 startup CEO 做技術決策
- 2026 Q1 出現 **Cursor Rules Marketplace**，開發者上傳銷售 Rules
- 平均每個熱門 Rule 被購買 200-500 次，訂價 $5-$29

**風向轉變：**
- 從「用 AI 幫我寫代碼」→「用 AI 專家Skill幫我」
- Skills 即將取代一般 Prompt Engineering，成為 AI 價值載體

### 2️⃣ MCP (Model Context Protocol) 生態爆發

**2026 Q1 MCP 生態關鍵數據：**
- 官方 MCP Servers 從 2025 Q4 的 50+ 增至 **300+**
- 第三方 Community Servers 超過 **2,000 個**
- MCP 生態已經覆蓋：
  - **Development:** GitHub, GitLab, Jira, Linear, Slack, Notion
  - **Data:** PostgreSQL, MongoDB, Google Sheets, Airtable
  - **Cloud:** AWS, GCP, Azure, Vercel, Cloudflare
  - **Communication:** Sendgrid, Twilio, Discord, Telegram

**MCP Skills 變現機會：**
1. **垂直領域 MCP Server** — 為特定行業構建定制 MCP 整合
   - 例：香港中小企常用的 Xero/MYOB 會計系統 MCP
   - 估計價值：每間公司 $50-200/month
   
2. **MCP Server Templates** — 快速建構 MCP 的 starter kits
   - 已在 Gumroad 上熱賣，訂價 $29-$99
   - 需求大：好多公司想內部部署 MCP 但唔知點開始

3. **MCP Monitoring/Management Tools** — 企業級 MCP 監控平台
   - 類似 DataDog 但專注 MCP Servers 健康狀況
   - 2026 Q1 出現多家新創做緊呢個領域

### 4️⃣ 可變現 Skills 方向建議

**🤔 我既假設係：**
基於市場空缺 + 變現潛力，我認為以下 3 個方向最有機會：

**方向 A: MCP Server for HK/Asia SME Tools**
- 香港 / 東南亞中小企常用嘅erp系統（SAP B1, Tally, Kingdee）
- 目前未有高質量 MCP 整合
- 市場壁壘：需要了解 Asia 特定系統 API
- **預計收入：$2000-10000/月 (B2B)**

**方向 B: Cursor Rules for Startup MVPs**
- 幫 startup 快速設定 "Production-Ready" Cursor Rules
- 包括：Next.js + Supabase + Vercel 完整 stack
- 可批量銷售 template，邊際成本接近零
- **預計收入：$500-3000/月被動收入**

**方向 C: Vertical AI Agent Skill Pack (地產/金融)**
- 香港地產市場夠大、保險市場係亞洲最大
- 構建「地產投資分析 Agent」或「保險建議 Agent」
- 透過 Skills 銷售，比整個 SaaS 更容易變現
- **預計收入：$3000-15000/月**
