## 🔥 本地商家短視頻痛點地圖

### 三大類本地商家痛點

#### 🏪 餐廳/餐飲

```
核心痛點:
- 不知道拍什麼 (食物影片看起來都差不多)
- 每天忙於營運，沒時間做內容
- 不知道如何展示「差異化」
- 害怕鏡頭、不會演
- 沒有專業設備

最高需求:
1. 「今日特餐」快速影片模板
2. 廚房幕後花絮 (建立真實感)
3. 食物展示技巧 (如何拍出食欲)
4. 顧客反應/User-generated content整合
5. 外賣/到店轉化技巧
```

#### 🛍️ 零售/服飾/精品

```
核心痛點:
- 產品太多，不知道重點展示哪些
- 模特兒/展示場面不足
- 季節性庫存壓力 (需要快速推新款)
- 網上 vs 實體店價格矛盾
- KOL合作成本高、效果難測

最高需求:
1. 「新品上架」快速視頻模板
2. 穿搭/搭配建議短視頻
3. 限量/季節性促銷視頻
4. 顧客試穿/開箱影片
5. 店鋪氛圍/環境展示
```

#### 💇 美容/健身/服務業

```
核心痛點:
- 服務難以用視覺呈現 (剪髮/按摩/健身動作)
- 結果呈現時間太長 (護膚/健身效果)
- 預約制，難以展示「當下」
- 客戶隱私顧慮
- 技術性強，難以通俗化

最高需求:
1. Before/After 短視頻套路
2. 過程展示 (建立信任)
3. 客戶見證/推薦影片
4. 技術解說短視頻 (專業感)
5. 團隊/技師介紹影片
```

## 🔥 2026年 Local Business Reels 熱門內容模式

### 餐廳/餐飲 — 病毒式內容公式

```
公式1: 「廚房24小時」系列
- 早上備料 → 中午高峰 → 晚上收店
- 真實感 + 職人精神 = 病毒潛力
- 變現: 到店消費 + 外賣平台引流

公式2: 「食物誕生過程」
- 一道菜的從零到成品
- 延時拍攝 (Time-lapse)
- ASMR 聲音元素
- 變現: 教學課程 + 食材銷售

公式3: 「老闆的一天」
- Personal brand = 餐廳品牌
- 真實工作場景
- 與員工/顧客的互動
- 變現: 粉絲忠誠度 + 加盟招商

公式4: 「限時特餐倒計時」
- scarcity + urgency
- 每日/每週更新
- 限時優惠碼追蹤
- 變現: 直接帶貨 + 到店客流

公式5: 「顧客反應牆」
- 設定「食物試吃」相機
- 真實顧客表情/反應
```

## ⚠️ 常見失敗原因與解決方案

### 本地商家做 Reels 常見錯誤

| 錯誤 | 描述 | 解決方案 |
|------|------|---------|
| **太商業化** | 只發促銷/廣告 | 80% 價值內容 + 20% 推銷 |
| **沒有特色** | 和其他餐廳看起來一樣 | 差異化 USP 要在首3秒展示 |
| **發布不規律** | 三天打魚兩天曬網 | 固定時間 + 排程發布 |
| **忽視留言** | 不回應互動 | 每一條留言都要回 |
| **過度完美** | 過度專業反而假 | 真實/即興更有吸引力 |
| **不懂演算法** | 不知道要什麼 | 完播率 > 讚 > 分享 > 留言 |
| **沒有CTA** | 看完不知道要幹嘛 | 每條影片要有明確行動呼籲 |

### 成功關鍵

```
1. 前3秒法則:
   - 鉤子必須在首3秒抓住注意力
   - 「今天給大家看看我們廚房...」
   - 「這道菜是我們老闆最愛...」

2. 90% 價值，10% 推銷:
   - 教育/娛樂/啟發 > 直接銷售
   - 推銷要軟性包裝

3. 數據優化:
   - 每週看 Analytics
   - 找出 Top 3 影片
   - 複製成功模式

4. 持續性:
   - 至少坚持 30 天
   - 不要因為初期沒有爆就放棄
   - 爆款需要累積
```
