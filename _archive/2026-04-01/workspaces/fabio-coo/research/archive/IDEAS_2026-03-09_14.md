## 🔥 AI Agent Sandbox 趨勢分析 (2026)

### Agent Safehouse - 個案分析

| 特性 | 說明 |
|------|------|
| **定位** | macOS-native sandboxing for local agents |
| **核心問題** | LLMs are probabilistic - 1% chance of disaster makes it a matter of when, not if |
| **技術架構** | 基於 macOS sandbox-exec profile |
| **熱度** | HN #1 - 679 points (2026-03-09) |

### 運作模式

```
~/project
agent: $ rm -rf ~
Safehouse: 你冇權限郁呢個！
```

**Deny-first access model:**
- 預設否決所有權限
- 明確授權先可以訪問
- 工作目錄 (git root) 自動獲得讀寫權限
- SSH keys, AWS credentials 預設封鎖

### 安全模型對比

| 模型 | 傳統方式 | Safehouse 方式 |
|------|----------|-----------------|
| **權限** | 繼承 user 所有權限 | Deny-first |
| **訪問控制** | 白名單 | 黑名單 |
| **默認狀態** | 全部可訪問 | 全部封鎖 |
| **災難風險** | 高 (1% 變 100%) | 低 (kernel-level block) |
