### 💡 MCP (Model Context Protocol) 生態

#### 點解 MCP 重要？
```
Traditional: Prompt → LLM → Output (Stateless)
MCP: Tool + Context + Memory → Stateful Agent
```

#### MCP 應用場景
1. **Database Integration** - 直接query SQL/NoSQL
2. **File System** - 讀寫代碼庫
3. **Web Fetch** - 即時資訊檢索
4. **Custom Tools** - 企業內部系統整合

#### 商業機會：MCP Server as a Service
- **痛點:** 企業想整閤 internal systems 但缺乏 developer resources
- **機會:** Pre-built MCP servers for popular SaaS (Salesforce, Notion, Slack)
- **定價:** $99-499/month per connection
