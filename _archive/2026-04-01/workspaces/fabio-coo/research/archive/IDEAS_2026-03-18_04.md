## 🔥 MCP 生態全景 2026

### 咩係 MCP?

**Model Context Protocol (MCP)** = AI 界既 USB-C
- 開放標準，連接 AI 應用與外部系統
- 等同一個標準化接口，唔洗好似以前咁為每個服務寫死 Code

**官方定義:**
> MCP is an open-source standard for connecting AI applications to external systems.

## 🔥 Cursor MCP Marketplace 分析

### Cursor Marketplace 現況

**官方功能:**
- One-click install MCP servers
- OAuth 認證
- Project-level + Global-level 配置
- Extension API for enterprise

### Transport Methods

| Transport | 環境 | 部署方式 | 用戶數 |
|-----------|------|----------|--------|
| **stdio** | Local | Cursor 管理 | 單用戶 |
| **SSE** | Local/Remote | Server 部署 | 多用戶 |
| **Streamable HTTP** | Local/Remote | Server 部署 | 多用戶 |

### MCP Apps Extension

- 可以返回互動式 UI
- Progressive enhancement (如果 host 唔支援，都可以用標準 response)
- 範例：Image generation, Data visualization
