## 🔬 2026 AI Agent 落地現況分析

### 一、關鍵轉捩點：2025 年 12 月

**Stratechery 最新分析 ("Agents Over Bubbles"):**

```
三個 LLM 發展拐點:

1. ChatGPT (Nov 2022)
   - 突破性但有缺陷
   - 會 hallucinate，需要用戶主動管理錯誤

2. o1 (Sep 2024)
   - 推理模型，會自我驗證
   - 大幅提升可靠性

3. Opus 4.5 / GPT-5.2-Codex (Nov/Dec 2025) ⭐
   - AI Agent 真正自主完成任務
   - 例如：自主 coding 數小時，正確完成
   - Agent 可以使用工具驗證結果
   - 人類無需介入每個步驟
```

**關鍵洞察：**
- AI Agent 已經可以自主完成可驗證的任務（coding 優先）
- 計算需求暴增：Agent 使用大量 tokens（推理 + 驗證 + 重試）
- 最大問題：「用 Agent 變現」而非「 Agent 技術本身」
