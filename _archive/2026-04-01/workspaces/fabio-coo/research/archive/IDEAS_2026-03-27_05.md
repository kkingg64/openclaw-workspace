## 🔬 MCP 生態全景分析

### 一、MCP 係什麼？

**Model Context Protocol (MCP)** 係一個開源協議，用於連接 AI 應用同外部數據源同工具。

```
比喻：MCP 就像 AI 應用既 USB-C 接口
- USB-C 標準化咗設備連接
- MCP 標準化咗 AI 連接外部系統
```

**支援既客戶端：**
- Claude (Anthropic)
- ChatGPT (OpenAI)
- Cursor
- VS Code (Copilot)
- OpenClaw
- 等等...
