## 🔍 平台演算法深度解密 (2026 Q1)

### TikTok Algorithm 2026

**核心信號優先級:**
```
1. Watch Time (最高權重) - 完整播放 > 重複觀看 > 分享
2. Engagement Rate - 讚、評、藏、分享、關注
3. Content Quality - 停留時間、Replay Value
4. Creator Credibility - 帳號信譽分數
5. User Satisfaction - 「不感興趣」反饋少
```

**2026 新演算法變化:**
| 變化 | 影響 |
|------|------|
| **Long-form 優先** | 1-3min 影片獲得更多推薦 |
| **電商信號強化** | In-video 購買行為影響推薦 |
| **AI Content 標記** | AI 生成內容需要 disclosed |
| **Local/Regional 增權** | 本地化內容更容易爆 |

### Instagram Reels Algorithm

**特別信號:**
```
- Save Rate (最高權重之一)
- Share to Stories Rate
- DM Send Rate
- Profile Visit Rate
- Follow After See
```

**2026 Reels 紅利期:**
| 時期 | 紅利 | 策略 |
|------|------|------|
| 新帳號首月 | 500% reach 放大 | 密集發布高質量 |
| 新功能上線 | 流量傾斜 | 率先使用 Reels 新功能 |
| 品牌合作 | 官方支持 | 加入品牌合作計劃 |

### YouTube Shorts Algorithm

**獨特邏輯:**
```
- 與 Long-form 視頻互補推薦
- Channel Authority 權重高
- Retention Curve 決定是否繼續推送
- Curation 階段決定是否病毒
```

**2026 Shorts 策略:**
| 策略 | 做法 |
|------|------|
| 鈎子前置 | 前3秒必須有「為什麼要看」 |
| CTA 設計 | 「追蹤看下一集」強提示 |
| 系列化 | 同一話題連續短片 |
| Cross-promotion | Shorts 導流 Long-form |
