#### 乜係 Agent Content Optimization?

| 概念 | 解釋 | 商機 |
|------|------|------|
| **Content Negotiation** | 檢測 Agent (Accept: text/markdown) | 中間件 |
| **Markdown 優先** | 減少 token，提高準確性 | 工具 |
| **結構化輸出** | 去掉無關既 navigation/JS | 開發服務 |
| **API First** | 設計 Agent 可以用既 API | 新興 |

#### Sentry 最佳實踐 (案例)

| 優化方向 | 做法 | 價值 |
|----------|------|------|
| **Doc 優化** | 真 markdown，去除 HTML | 50%+ token 節省 |
| **Agent Hook** | 檢測 Accept header | 自動提供 MCP/CLI |
| **Sitemap** | 給 Agent睇既目錄 | 快速理解結構 |
| **MCP Server** | 結構化數據接口 | 無需 HTML parsing |
