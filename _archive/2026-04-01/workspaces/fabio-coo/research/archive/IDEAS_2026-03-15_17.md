### 🔗 MCP (Model Context Protocol) 生態爆發

#### MCP 核心價值

**MCP 解決既問題：**
- 以前：AI 需要個別 API 連接每個工具
- 現在：統一協議，一次連接，自動發現功能

#### MCP Servers 生態

| 類別 | 熱門 Server | 應用場景 |
|------|-------------|----------|
| **開發工具** | GitHub, Git, Filesystem | 程式開發 |
| **數據庫** | PostgreSQL, SQLite, MongoDB | 數據查詢 |
| **通訊** | Slack, Discord, Linear | 團隊協作 |
| **雲服務** | AWS, GCP, Azure | 基礎設施 |
| **搜尋** | Brave Search, Web | 資訊檢索 |

#### MCP Registry 新上線

**2026 March 最新：**
- GitHub 正式推出 MCP Registry
- 整合外部工具變得更簡單
- **Marketplace 效應：** 第三方 MCP Server 將爆發
