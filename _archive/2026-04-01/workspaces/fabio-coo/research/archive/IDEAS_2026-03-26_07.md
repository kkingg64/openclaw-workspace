## 🔥 病毒式傳播內容的底層規律 (2026 Q1)

### 1. 情緒觸發係核心驅動力

**數據參考：**
- 高情緒觸發內容 (驚喜、搞笑、感動) 比普通內容互動率高 **3-7x**
- 「驚喜/不可思議」類內容 shares 率最高
- 「知識乾貨」類內容 saves 率最高（收藏後看）


**2026 Q1 新趨勢：**
- **「情緒反轉」** 仍係王牌：前 3 秒製造預期，最後 1 秒反轉

- **「陪伴感」** 角色視角內容（第一人生成視角）互動率高

### 2. Hook Formula（抓眼球公式）

**黃金 3 秒法則：**
- 用戶平均注意力 < 1.5 秒決定划走還是繼續看
- 前 3 秒必須包含：視覺奇觀、情緒觸發、或悬念

```
┌─────────────────────────────────────────────────────────────────────────┐
│              PROVEN HOOK FORMULAS (2026 Q1 驗證有效)                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  1. 【震驚數字开场】                                                     │
│     「你知唔知 [X] 係全球耗水量最多既野？」                                │
│     「呢個化妝師用 $5 整出 $5000 效果」                                    │
│     → 數字具體化，激發好奇心                                             │
│                                                                          │
│  2. 【挑釁式陳述】                                                       │
│     「所有香港人都犯咗呢個錯...」                                         │
│     「減肥期間絶對唔可以食嘅嘢（大部分人都做錯）」                         │
│     → 引起不服氣情緒，留住看完                                           │
│                                                                          │
│  3. 【第一人稱敘事】                                                     │
│     「我挑戰 30 日只靠 AI 搵錢，結果...」                                 │
│     → 建立陪伴感，觀眾想知結果                                           │
│                                                                          │
│  4. 【視覺奇觀开场】                                                     │
│     無聲但畫面衝擊：爆破解壓食品、水彩融合、城市航拍                       │
│     → 前 3 秒靠視覺抓人                                                  │
│                                                                          │
│  5. 【熱門 sound + 新場景】                                             │
│     用當紅音樂，但呈現全新、未預期場景                                    │
│     → 借趨勢流量 + 創新內容                                              │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3. 演算法偏好正在改變 (2026 Q1)

**2025 vs 2026 演算法變化：**

```
┌─────────────────────────────────────────────────────────────────────────┐
│              PLATFORM ALGORITHM SHIFTS (2025 → 2026)                      │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  TikTok:                                                                 │
│  ├── 2025: Watch time > Likes > Comments > Shares                       │
│  ├── 2026: Engagement rate (saves + shares) > Watch time > Likes       │
│  ├── 信號：「呢條片值唔值得分享？」取代「幾多人完整睇完？」                │
│  └── 影響：知識型、工具型內容获流量提升                                   │
│                                                                          │
│  Instagram Reels:                                                        │
│  ├── 2025: Follower-based reach 為主                                    │
│  ├── 2026: Explore 流量佔比提升至 40%+                                   │
│  ├── 信號：平台主動推動新帳號、新內容曝光                                 │
│  └── 影響：新手 Creator 有更多被看見機會                                 │
│                                                                          │
│  YouTube Shorts:                                                         │
│  ├── 2025: CTR (點擊率) > Watch time                                    │
│  ├── 2026: Retention curve (觀看時長分佈) 更重要                          │
│  ├── 信號：唔只睇幾多人點擊，仲睇幾時走（3秒走 vs 30秒走）               │
│  └── 影響：片頭前 3 秒更關鍵，需要立即抓眼球                              │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4. AI + 人格化 IP 係突圍關鍵

**為何純 AI 內容唔夠：**
- AI 生成視頻大量湧入，用户开始审美疲劳
- 無人格 IP 的 AI 內容容易被划走
- 演算法開始識別「AI content farm」並降權

**成功的 AI + 人格化模式：**
