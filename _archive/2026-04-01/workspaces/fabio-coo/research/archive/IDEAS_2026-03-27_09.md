## 🔬 AI Coding Agent Skills 生態分析

### 一、主流平台現況 (2026 Q1)

#### Claude Code (Anthropic)
- 定位：企業級 AI coding agent
- 強項：代碼質量、Security、Enterprise 整合
- Skills：支援允許工具清單、project-specific 設定
- 生態：開放 Anthropic 插件系統，第三方 Skills 正在起來

#### Cursor (AI-first IDE)
- 定位：AI-native 開發者工具
- 強項：Composer、Agent mode、MCP 原生支援
- MCP 支援：
  - stdio（本地單用戶）
  - SSE / Streamable HTTP（遠程多用户）
  - OAuth 認證
  - MCP Apps（互動式 UI 擴展）
- Skills 市集：cursor.directory（第三方 community 主導）

#### GitHub Copilot
- 定位：Microsoft 生態嘅 AI 編碼助手
- 強項：VS Code 深度整合、Enterprise security
- MCP：支援 MCP Registry 擴展

### 二、MCP 生態系統（核心機會）

#### MCP 係咩？
Model Context Protocol = AI 應用嘅「USB-C」
- 標準化介面，連接 AI 至外部工具同數據源
- 一個 MCP server 可以俾 Claude、Cursor、ChatGPT、VS Code 同時用
- 減少重複開發：Build once, run everywhere

#### MCP 可以做到乜？
| 能力 | 應用場景 |
|------|---------|
| **Tools** | AI 執行函式（搜尋、計算、API 調用） |
| **Prompts** | 範本化訊息同工作流 |
| **Resources** | 結構化數據源（DB、File System） |
| **Roots** | 服務器查詢 filesystem 邊界 |
| **Elicitation** | 服務器向用戶請求更多資訊 |
| **MCP Apps** | 互動式 UI（AI 返回按鈕、表單） |

#### 熱門 MCP Servers（2026 已驗證方向）
1. **Figma** - AI 直接操作 design files
2. **Google Calendar / Notion** - 個人 AI 助手
3. **Database** - Enterprise 數據分析 chatbot
4. **Blender** - 3D design AI
5. **Search / Calculator** - 基礎工具增強

### 三、Skills 變現機會地圖

#### 機會 1: MCP Skills Package（似 App Store）
**定位：** 垂直行業一站式 MCP 組合
**例子：**
- E-commerce MCP Pack（Shopify + Stripe + 物流 API）
- Legal Tech MCP Pack（合同分析 + 法規查詢）
- Healthcare MCP Pack（病歷系統 + 預約 API）

**變現：** $29-199/month 訂閱 或 單次購買 $9-49

#### 機會 2: AI Agent Freelance Skills（服務變現）
**定位：** 幫企業定制 AI agent workflow
**熱門需求：**
- CRM 整合（HubSpot, Salesforce）
- 數據清洗 pipeline
- 自動化報告生成
- 代碼審查 workflow

**收費：** $500-5000/project 或 $150-300/hour

#### 機會 3: Skills Templates（教育變現）
**定位：** 教人點整 AI Agent Skills
**內容：**
- Notion Template + Video Course
- MCP Server 開發教程
- Cursor/C克劳 Code 最佳實踐

**變現：** $49-299/course 或 $99-499/mentorship program

#### 機會 4: MCP Server 開發服務
**定位：** 幫公司建立私有 MCP servers
**需求：** 
- 數據安全要求高嘅金融、醫療行業
- 內部工具封裝
- 定制 AI 工作流

**收費：** $2000-20000/project

### 四、MCP Apps 新興方向（MCP 延伸）

MCP Apps = AI tool 返回互動式 UI（按鈕、表單、儀表板）

**商業潛力：**
- AI 返回 「✅ Confirm」/「❌ Cancel」Button
- AI 返回完整 Table/Form
- AI 返回 Charts/Visualizations

**變現場景：**
- 做 MCP Apps 模板（$29-99）
- 幫其他 developer 整 MCP Apps（freelance）
- MCP Apps 案例網站/作品集（引流）
