## 🎯 AI Agent Micro-SaaS 生態全景

### 什麼是 AI Agent Micro-SaaS？

**定義:** 以 AI Agent 為核心競爭力嘅細規模 SaaS (通常 MRR $1K-$50K)，由 1-5 人營運，專注單一垂直場景或單一任務自動化。

**特徵:**
- 極低營運成本 (月均 $200-$2,000)
- 單一功能做到極致
- 快速疊代市場驗證
- 通常係 founder-led sales
- 多採用 usage-based pricing

**與傳統 SaaS 唔同:**
| 維度 | 傳統 SaaS | AI Agent Micro-SaaS |
|------|-----------|---------------------|
| 開發周期 | 6-18 個月 | 2-8 週 |
| 初期投入 | $100K+ | <$10K |
| 定價 | $99-$999/月 | $19-$299/月 |
| 客戶獲取 | 銷售團隊 | 產品驅動 + 内容營銷 |
| 擴展方式 | 增加功能 | 增加用量客戶 |

## 🚀 Micro-SaaS vs Macro-SaaS 決策框架

### 幾時選擇 Micro-SaaS？

```
✅ 適合 Micro-SaaS:
- 個人或極小團隊 (1-3人)
- 想驗證想法、快速失敗
- 有限啟動資金 (<$10K)
- 想保持靈活、可轉向
- 熱情驅動而非 VC 驅動
- 想要 lifestyle business (被動收入)

❌ 不適合 Micro-SaaS:
- 目標係 IPO 或巨型退出
- 需要大量工程資源
- 進入高監管行業 (需要認證/合規)
- 想做平台型 business
```

### Micro-SaaS 成功關鍵指標

| 指標 | 目標 (6個月) | 優秀 | 備註 |
|------|-------------|------|------|
| MRR | $2K | $10K+ | 每月 recurring |
| 客戶數 | 50 | 200+ | 分散風險 |
| 流失率 | <10%/月 | <5%/月 | product-market fit 信號 |
| Burn Rate | <$500/月 | <$200/月 | 保持輕量 |
| CAC | <$50 | <$20 | 依賴有機增長 |
| LTV:CAC | >3:1 | >5:1 | 健康比率 |

## 💰 Micro-SaaS 成本控制策略

### 極低成本營運框架

```
每月固定成本控制:
┌────────────────────────────────────────────┐
│           極簡 Micro-SaaS Stack            │
├────────────────────────────────────────────┤
│                                            │
│  開發: Cursor / Claude Code (Free)         │
│  托管: Vercel / Railway / Fly.io (Free tier)│
│  數據庫: Supabase / PlanetScale (Free tier)│
│  支付: Stripe (2.9% + 30¢ per txn)         │
│  電郵: Resend (Free 100/day)               │
│  域名: Namecheap ($10/year)               │
│  AI API: OpenAI / Anthropic (Pay-as-you-go) │
│                                            │
│  總月均成本: $200-500                      │
│                                            │
└────────────────────────────────────────────┘

策略:
1. 全部用免費 tier 起步
2. 等收入穩定先升級
3. AI API 成本要 careful (设 limits)
4. 唔好prematurely 請人
```

### AI API 成本管理技巧

```
成本陷阱:
- Unlimited AI generation = Unlimited cost
- Complex agents = Multiple API calls per task
- Long context = Exponential cost growth

控制方法:
1. 設每用戶每月 AI token limits
2. Cache common responses
3. 優先用便宜的 model (Claude Haiku > GPT-4o)
4. 設計 simple agents 減少 steps
5. Usage alerts + auto-disable

目標: AI API cost < 20% of revenue
```
