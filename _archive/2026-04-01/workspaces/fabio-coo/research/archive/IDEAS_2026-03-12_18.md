---

#### 2. "Agentic" 程度光譜 (關鍵概念)

**Andrew Ng 既觀點:**
- 唔好拗乜嘢係「真正既 AI agent」
- 應該睇「有幾 agentic」— 係一個 spectrum

**5 個層次:**

| 層次 | 名稱 | 描述 | 商業價值 |
|------|------|------|----------|
| L1 | Router | LLM 做簡單 routing | 低 |
| L2 | Multi-LLM Router | 多個 LLM 協作 | 中 |
| L3 | State Machine | 可以 loop until finish | 中高 |
| L4 | Tool Builder | Agent 自己製造 tools | 高 |
| L5 | Fully Autonomous | 自主規劃同執行 | 好高 |

**商業洞察:**
- 大多數企業仲响 L1-L3
- L4-L5 係未來機會，但風險高
- **Tooling 同 observability** 响任何層次都係剛需

#### 3. SaaS 市場缺口分析

**機會 1: Agent Observability Platform**

| 現有解決方案 | 不足之處 |
|-------------|----------|
| LangSmith | 貴，企業級 |
| Phoenix (Arize) | 主要 ML focus |
| Datadog | 非原生 AI |

**缺口:** 中小型團隊用得起既 AI agent monitoring
**估計市場:** $2-5B TAM

---

**機會 2: Agent Evaluation & Testing**

| 需求 | 點解重要 |
|------|----------|
| Agent 行為隨機性高 | 需要多次運行 eval |
| 中間步驟要測試 | 唔只要 output，過程都要優化 |
| Compound errors | 小錯會累積放大 |

**缺口:** 專門做 Agent testing 既 SaaS
**估計市場:** $1-3B TAM

---

**機會 3: Agent-to-Agent (A2A) 通信標準**

**趨勢:**
- MCP (Model Context Protocol) 响 2025-2026 崛起
- 但 MCP 主要係「Agent ↔ Tool」連接
- 「Agent ↔ Agent」通信標準仲係早期

**機會:** A2A protocol + marketplace
**估計市場:** $500M-2B TAM

---

**機會 4: No-Code / Low-Code Agent Builder**

| 玩家 | 定位 |
|------|------|
| AI21 | Enterprise focus |
| Relevance AI | No-code |
| Dust | 細粒度 control |

**缺口:** 中小企业用得爽既 visual agent builder
**估計市場:** $3-8B TAM

### 💰 商業價值總結

**高優先機會:**

1. **Agent Observability SaaS** (中小團隊版)
   - Target: 10-50 人既 AI 團隊
   - Pricing: $50-200/mo
   - 關鍵: 易用 > 功能多

2. **No-Code Agent Builder**
   - Target: Non-technical business users
   - 關鍵: Template marketplace
   - 可變現: 訂閱 + template sales

3. **垂直領域 Agent**
   - Finance agent, HR agent, Legal agent
   - 需要 domain knowledge + compliance
