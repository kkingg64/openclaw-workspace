## 📰 關鍵資訊整理

### 1. Mozilla cq：「Stack Overflow for Agents」- 知識共享新範式

**什麼是 cq：**
- Mozilla AI 開發的開源項目，定位為「Agent 之間的 Stack Overflow」
- 核心功能：AI Agent 在執行新任務前，先查詢 cq commons 共享知識庫
- 如果其他 Agent 已解決過同樣問題（例如「Stripe 用 200 status code + error body 表示 rate limit」），你的 Agent 自動知道，唔需要重新摸索

**技術架構：**
- Claude Code Plugin + OpenCode Plugin
- MCP Server 管理本地知識庫
- Team API 支援組織內共享
- 人類審核 UI（Human-in-the-loop review）
- 容器化部署

**商業啟示：**
```
【cq 模式嘅商業價值】

1. 減少重複勞動：每個 Agent 獨立解決同樣問題 = 巨大 tokens 浪費
2. 信任機制：知識經過多個 Agent、多個 codebases 驗證後先被信任
3. 平台效應：越多 Agent 參與，知識質量越高，形成網絡效應
4. 開源策略：Mozilla 選擇开源 = 不想重蹈 Stack Overflow 被 LLMs hollow out 嘅覆轍

風險：
- 需要大量 Agent 參與才能形成網絡效應
- 知識老化問題（同 Stack Overflow 一樣）
- 商業模式未明（Mozilla 定位為公共財）
```
