#### 1. **ReMe** — Memory Management Kit for Agents (本次首選)

| 項目 | 詳情 |
|------|------|
| **Stars** | 2,035 (+982 this week) |
| **語言** | Python |
| **官網** | https://github.com/agentscope-ai/ReMe |
| **PyPI** | `pip install reme-ai` |

**核心功能:**
- 🧠 **Agent 記憶管理框架** - "Remember Me, Refine Me"
- 📝 **File-based Memory** - 用 Markdown 文件儲存記憶 (同 OpenClaw 一樣！)
- 🔍 **Semantic Search** - Hybrid retrieval (vectors + BM25)
- 📦 **Context Compaction** - 自動壓縮長對話，保留重點
- 🔄 **Session 延續** - 新 session 可以繼承歷史 context

**解決既問題:**

| 問題 | ReMe 解決方案 |
|------|--------------|
| Context Window 限制 | Context compaction - 超過 threshold 自動壓縮 |
| 早期資訊丢失 | Summary 寫入 memory/YYYY-MM-DD.md |
| Stateless Sessions | File-based storage，新 session 可讀取歷史 |
| Long Tool Outputs | 自動截斷 + tool_result/ cache |

**Architecture:**

```
working_dir/
├── MEMORY.md              # Long-term memory: user preferences
├── memory/
│   └── YYYY-MM-DD.md      # Daily journal
└── tool_result/           # Long tool output cache
```

**API 亮點:**
```python
# 1. Context 檢查
await reme.check_context(messages)

# 2. 壓縮歷史為 summary
await reme.compact_memory(messages, max_input_length=128000)

# 3. 背景 Summary (非阻塞)
reme.add_async_summary_task(messages)

# 4. Pre-reasoning hook (auto compact)
processed_messages = await reme.pre_reasoning_hook(...)

# 5. Semantic memory search
result = await reme.memory_search(query="偏好", max_results=5)
```
