## 🎯 Coding Agent 平台 2026 Q1 最新動態

### 1. Cursor - Composer 2 + Automations

**最新版本亮點:**

| 功能 | 說明 | 商業影響 |
|------|------|----------|
| Composer 2 | Frontier-level coding performance, 強勁 benchmark 結果 | 取代複雜多文件任務的首選 |
| Standard/Fast 定價 | Standard: $0.50/M input, $2.50/M output; Fast: $1.50/M input, $7.50/M output | 成本可控的企業級服務 |
| Automations | Always-on agents，基於 schedule 或 events (Slack, Linear, GitHub, PagerDuty) 觸發 | 顛覆傳統 CI/CD 工作流 |
| JetBrains ACP | 透過 Agent Client Protocol 進入 IntelliJ IDEA、PyCharm、WebStorm | 擴大市場覆蓋 |

**Cursor Marketplace 新插件 (30+ 新增):**
- Atlassian, Datadog, GitLab, Glean, Hugging Face, monday.com, PlanetScale
- 這些插件包含 MCPs，讓 cloud agents 可自動化執行任務

**MCP Apps (新功能):**
- 在 Cursor chat 內支援互動式 UI
- 圖表工具: Amplitude
- 設計工具: Figma  
- 白板工具: tldraw

**Team Marketplaces for Plugins:**
- Teams 和 Enterprise 計劃支援私人插件市場
- 中央治理和訪問控制

**關鍵洞察:** Cursor 正在從 "AI Editor" 轉型為 "AI Development Platform"，Automations 功能標誌著 AI Agent 進入生產環境。

### 2. GitHub Copilot - Agents 時代

**Copilot 最新定位:**

```
"Command your craft - Your AI accelerator for every workflow, 
from the editor to the enterprise."
```

**核心更新方向:**

| 功能 | 說明 | 差異化點 |
|------|------|----------|
| Custom Agents | 使用自己的 agents、第三方 agents (Claude, OpenAI Codex) | 開放生態 |
| MCP Server Access Control | 企業可控制開發者可以訪問哪些 MCP servers | 安全合規 |
| Copilot Spaces | 企業內部知識庫整合，創建共享 context | 知識管理 |
| Agent Mode | 在 IDE 內 autonomous coding、PR creation、feedback response | 完整工作流 |

**Enterprise 定制能力:**
- 自定義 AI 知道的內容
- 自定義 AI 如何行動
- 自定義 AI 連接到哪裡 (MCP servers)

**關鍵洞察:** GitHub Copilot 正從 "AI pair programmer" 升級為 "AI Development Platform"，強調企業級控制和整合。
