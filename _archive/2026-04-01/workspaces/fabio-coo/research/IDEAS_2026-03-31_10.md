### 1.3 定價策略成功關鍵

```
收入最大化公式:

                ┌─────────────────────────────────────┐
                │         PRICING POWER               │
                │                                      │
                │   Price = Value Created × 0.1-0.3   │
                │                                      │
                │   Value = (Time Saved × Hourly Rate)  │
                │           + (Errors Avoided × Cost)  │
                │           + (Revenue Generated)      │
                │                                      │
                └─────────────────────────────────────┘

關鍵洞察:
- 幫客戶賺 $10K/月 → 可收 $1K-3K/月 (10-30% value share)
- 幫客戶省 10hrs/week → 按 $50-200/hr = $2K-10K value
- 避免一次過錯誤 $50K → 可以收 $5K-15K/次

定價心理學:
- $99/mo vs $999/mo: 99 感覺便宜但 999 利潤更高
- Anchor pricing: 先展示 $10K 版本，再推 $999 Pro
- Freemium: 5% conversion 是 industry standard
```

#### 🥇 路徑 1: AI Skills Store (最高 ROI)

**為何係黃金路徑:**
```
優點:
├── 邊際成本接近零 (寫一次，賣 N 次)

├── 需要 initial skill catalog
├── 需要 discoverability (行銷)
└── Competition from generalists

- Average skill price: $29-299 (one-time) 或 $5-50/mo

- 100 paying users × 3 skills avg = $60K MRR per skill category

```

### 4.3 Usage-based 定價心理學

```
關鍵原則:

1. **Anchor 效應**
   - 展示 $999/mo Enterprise，再展示 $99/mo Pro
   - Pro 突然顯得便宜

2. **損失厭惡 (Loss Aversion)**
   - "Don't lose your data" > "Gain access to data"
   - 用分手感，少用戶流失

3. **Decoy Pricing**
   - 提供 3 個 tier，讓中間那個顯得合理
   - 例: $29 (basic) / $49 (popular) / $199 (pro)
   - Popular = 預設選擇

4. **Freemium → Paid 轉化**
   - 5% 是 industry standard
   - 目標: 10% (需要良好 onboarding)
   - 關鍵: 第一個 value moment < 5 minutes

5. **Usage Cap 心理**
   - 唔好太 aggressive (用戶 feel trapped)
   - 提供 soft limit + overage option
   - 比 hard cut-off 用戶體驗更好
```
